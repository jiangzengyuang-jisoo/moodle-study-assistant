# Moodle 学习助手（DeepSeek Harness 插件）

直连学校 Moodle 的只读学习助手：在聊天里按章节学习本机保存的课程资料。安装后由插件引导完成学校登录、选择课程和资料范围，之后学习过程不需要复制命令或修改配置文件。

## 安装（学生）

1. 打开 DeepSeek Harness 左侧 **Plugins** 页 → **Add plugin**。
2. 粘贴试用包文件夹的绝对路径（或 `.tgz` 文件路径）→ 阅读第三方插件提示 → 点 **Install**。
3. 安装完成后保持插件开关为 **On**；首次使用在聊天里说“帮我设置 Moodle 学习助手”，按引导完成。

插件本身不包含任何账号、凭据或课程资料。个人学习资料保存在学生自己选择的文件夹，升级或卸载插件不会删除。

## 首次使用会做什么

1. 选择资料保存位置（默认 `文档\MoodleStudy`）；
2. 安装本地运行依赖（约 20MB，联网）；
3. 在浏览器打开学校登录页，由学生本人完成登录；
4. 选择课程并确认资料范围（完整同步 / 只同步课程信息）；
5. 首次同步学校信息与已授权资料，然后即可在聊天中学习。

## 数据与边界

- 学习资料、配置和 Windows DPAPI 加密的学校授权只保存在学生选择的资料目录。
- 插件目录不保存个人数据；升级插件或重装不影响的资料目录。
- 只读学校接口：不提交作业、不代替作答、不发帖、不修改学校完成状态。
- 详细使用说明、隐私说明和卸载/清理方法见插件详情页与随包文档。
