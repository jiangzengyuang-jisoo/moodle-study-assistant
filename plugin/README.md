# Moodle 学习助手（DeepSeek Harness 插件）

直连学校 Moodle 的只读学习助手：在聊天里按章节学习本机保存的课程资料。安装后由插件引导完成学校登录、选择课程和资料范围，之后学习过程不需要复制命令或修改配置文件。

## 安装（学生）

发布到 npm 后，推荐在 DeepSeek Harness 的 **Plugins → Discover** 中添加社区插件目录，再安装 **Moodle 学习助手（Windows 试用版）**；也可以直接安装 npm 包 `dsh-moodle-study@0.6.0-trial.3`。如果使用离线试用包，按下面的本地方式安装：

1. 打开 DeepSeek Harness 左侧 **Plugins** 页 → **Add plugin**。
2. 粘贴试用包文件夹的绝对路径（或 `.tgz` 文件路径）→ 阅读第三方插件提示 → 点 **Install**。
3. 安装完成后保持插件开关为 **On**；首次使用在聊天里说“帮我设置 Moodle 学习助手”，按引导完成。

插件本身不包含任何账号、凭据或课程资料。个人学习资料保存在学生自己选择的文件夹，升级或卸载插件不会删除。

## 首次使用会做什么

1. 选择资料保存位置（默认 `文档\MoodleStudy`）；
2. 安装本地运行依赖（约 20MB，联网）；
3. 在浏览器打开学校登录页，由学生本人完成登录；
4. 选择课程并确认资料范围（完整同步 / 只同步课程信息）；
5. 首次同步学校信息与已授权资料，证据齐备后完成设置，即可在聊天中学习。

## 设置中断、断网与调整设置

- **断点续设**：设置进度保存在本机。任何一步中断（关聊天、退出、断网、安装失败、同步失败）后重新打开聊天，助手会从当前进度继续，不会删除已有资料。
- **完成判定看真实同步证据**：空资料目录、同步未开始/失败/中断/部分完成不会显示为设置完成；助手会说明每门课程的可用范围与下一步，重跑同步是增量的，已成功的资料不重复下载。
- **断网也能继续学习**：学校暂时连不上时，仍可读取本机资料、按章节讲解并继续教学记录；需要最新学校信息时助手会说明“当前不是最新线上结果”，不承诺离线模型推理。
- **连接状态与重新登录**：网络故障重试连接即可（`study_reconnect`），不需要重新登录；只有登录失效或凭据无法解密才需要本人重新连接学校。
- **更换课程/资料位置/修复依赖**：都可以在聊天里完成。更换资料位置时旧文件夹原样保留；旧登录凭据不会复制到新位置；重跑依赖安装会跳过已完成步骤。
- 登录成功或更换资料位置后工具会自动重连（几秒，工具名不变）。

## 数据与边界

- 学习资料、配置和 Windows DPAPI 加密的学校授权只保存在学生选择的资料目录。
- 插件目录不保存个人数据；升级或重装插件不影响学生选择的资料目录。
- 只读学校接口：不提交作业、不代替作答、不发帖、不修改学校完成状态。
- 详细使用说明、隐私说明和卸载/清理方法见插件详情页与随包文档。
