# Moodle 学习助手

在 DeepSeek Harness 的聊天里直接学习本机保存的 Moodle 课程资料：按章节深入讲解、核对本章文件、记录教学位置，并在需要时读取学校最新的作业与公告。学校接口只读，不提交作业、不代替作答、不发帖、不修改完成状态。

## 适合谁

- 已在本校 Moodle 学习、希望用自己的课件在聊天里按章节学习的学生；
- 希望资料留在自己电脑、由自己选择保存位置，而不是上传到第三方平台的学生。

## 安装

发布到 npm 后，推荐在 DeepSeek Harness 的 **Plugins → Discover** 中添加社区插件目录，再安装 **Moodle 学习助手（Windows 试用版）**；也可以直接安装 npm 包 `dsh-moodle-study@0.6.0-trial.7`。使用离线试用包时：

1. 打开 DeepSeek Harness 左侧 **Plugins** → **Add plugin**。
2. 粘贴试用包文件夹的绝对路径（或 `.tgz` 文件路径），阅读第三方插件说明后点 **Install**。
3. 安装后确认插件开关为 **On**，新开聊天说“帮我设置 Moodle 学习助手”。

安装不需要预先安装 Node、Python、pnpm 或修改任何配置文件；脚本运行环境由 Harness 自带或由插件自动准备。

## 首次使用

1. **选择资料位置**：默认 `文档\MoodleStudy`，也可以指定其他文件夹。已有学习资料文件夹会被直接沿用，不会覆盖记录。
2. **安装运行依赖**：插件自动使用 Harness 自带的 Python 建立私有运行环境（约 20MB 下载）。
3. **连接学校账号**：学校登录页会在本机浏览器打开，由学生本人完成登录（可含验证码/双重验证）。插件不读取密码或 Cookie。
4. **选择课程与资料范围**：“完整资料同步”会下载并索引所选课程资料；“只同步课程信息”不下载资料。
5. **首次同步并完成设置**：采集当前学校信息并按授权同步资料；只有真实同步证据匹配当前账号与课程授权时设置才会完成，之后即可开始学习。

每一步都会在聊天里给出明确状态。登录成功或更换资料位置后，工具会自动重新连接（几秒，工具名不变）。设置进度、资料和登录状态都保存在本地：**任何一步中断后重新打开聊天都会从当前进度继续**，不需要从头再来，也不会删除已有资料。

**完成判定以真实同步证据为准**：只有学校采集快照与资料同步报告齐全、且匹配当前账号、课程和授权范围时，设置才会被标记为完成。选择“完整资料同步”时，还要求学校信息采集记录本身完整（例如作业/公告查询不能超时失败）；采集失败时即使课件已下载成功也不会标记完成，已下载资料会保留。空资料目录、同步尚未开始、失败、中断、只完成一部分、采集不完整或证据过期时，助手会说明每门课程的可用范围与剩余问题，并可以重跑同步增量补齐（不会重复下载已成功内容）。

## 设置维护与恢复

- **更换课程或资料范围**：在聊天里说明要调整，助手会重新列出课程，等你确认后再保存新选择；已确认的旧资料保留。
- **更换资料位置**：可以换到另一个文件夹，旧文件夹原样保留；旧文件夹的登录凭据不会复制到新位置，如果新位置还没有自己的登录，联网时需由你本人重新连接学校一次。
- **修复运行依赖**：安装中断或运行环境损坏时，可让助手重跑依赖安装，已完成的步骤会跳过，不需要重装插件。
- **断网也能继续学习**：学校暂时连不上时，助手仍可读取本机资料、按章节讲解并继续之前的教学记录；涉及最新作业、公告或考试信息时，助手会说明“当前不是最新线上结果”，不会声称已完成同步或已核验最新版本。
- **连接状态与重新登录的区别**：网络/接口暂时失败时，重试连接即可，不需要重新登录；只有登录失效或本机凭据无法解密时，才需要你本人重新在学校网页登录。
- **增量同步**：同步中断或部分失败后重跑会补齐剩余内容，已下载成功的资料不会重复下载。

## 学习时的行为

- 默认一次深入讲清一个适量知识点：概念、符号、适用条件、示范，再留一个理解检查；明确要求整章讲义或完整答案时按要求一次交付。
- 数学公式使用可渲染的 LaTeX 表达。
- 指定章节时只准备和讲解该章，不自动扩大为全部课程刷新或旧章节追问。
- 章节核对使用 Harness 内的 Moodle 工具完成，同一聊天、同一章节且本地资料未变时复用核对回执，不重复联网；不需要为日常核对授予命令权限。
- 教学末尾不堆积技术日志或核验回执；只有资料缺失或不确定性实际影响讲解时才简短说明。

## 数据与隐私

- 个人学习数据（课程、笔记、错题、复习记录、教学位置、资料原件）只保存在学生选择的资料目录。
- 学校 API Token 由现有 Windows DPAPI 机制加密保存在资料目录的 `.private/` 内，只对当前 Windows 用户可解密；插件不把 Token 写入聊天、日志或配置。
- 插件安装目录只包含程序与通用规则；升级插件不会改动学习数据。
- 资料位置不能选在插件安装包目录（含其内部文件夹）里：插件升级、修复或卸载会替换整个安装包。选择独立文件夹即可，已有独立资料目录不受影响。
- 卸载插件默认保留资料目录；如需彻底删除，由学生自行删除其选择的资料文件夹和 Harness 支持目录（`%LOCALAPPDATA%\MoodleStudyAssistant`，其中只有运行环境与日志）。

## 已知限制

- 仅支持 Windows（学校登录与凭据保护依赖 Windows DPAPI 和系统 Edge/Chrome）。
- 首次安装需要联网下载 Python 依赖；网络受限时会给出失败原因与重试入口。
- 学校必须启用 Moodle Mobile Web Service；具体权限由学校控制。
- DOCX/PPTX 资料没有页图，只能读取抽取文字；数学公式核对应以 PDF 原页为准。
- **本地保存不等于离线推理**：断网时只保证读取本机资料与本地教学记录，不承诺模型离线推理，模型调用仍依赖 Harness 当前的模型服务。
- 插件没有编程/命令行工具，不执行任意命令，也不下载授权范围外的内容。
- 当前为试用版：真实学校账号登录、不同电脑与 Windows 账户的安装表现尚未全部验证；试用中如遇到问题，先按恢复入口处理并保留资料目录。

## 卸载与恢复

在 **Plugins** 页卸载插件后，个人资料目录与 Harness 支持目录会保留。重新安装插件并选择原来的资料文件夹即可继续使用；如学校登录失效，重新连接一次即可。旧版设置做到一半时升级，也不会丢失进度，重新打开聊天后会从当前步骤继续。
