# 发布范围与验收

本版面向 Windows，默认香港时区，学习工具按 `state.timezone` 使用配置的 IANA 时区；沿用已在 HKU 使用的 Moodle API 采集、FSRS 和 SymPy，提供独立空白学习目录。新同学用自己的官方 API Token，浏览器登录方式另提供实验性 SSO 辅助。不包含作者课程、作答、日程、课件、题库或凭据。

## 功能边界

- `tools/moodle/`：只读采集、学校官方授权连接，以及明确请求后按指定模块获取资料的独立下载入口。默认刷新不下载。
- `tools/study/learning_loop.py`、`planning.py`、`daily.py`：具体核验题目、真实独立尝试、答案曝光、FSRS 复测、反馈和日期/版本一致的当前页面。
- `exam_sources.py`、`exam_prep.py`、`coverage.py`：考试说明溯源、三种模拟卷模式、批改记录、考前覆盖和每周复盘。
- `library.py` 及配套模块：最新状态的按需上下文、逐页资料缓存、完整页读取、来源哈希、原页渲染及可选 Windows OCR；不修改学习状态或原件。
- `SKILL.md` 与 `docs/`：指导 AI 读取实际材料、编写原创题、检查答案并调用工具；不把程序描述成自动理解课件的模型。

工具不会自动训练个人时间模型、判断整章掌握或预测考试分数。当前页面按消息触发的运行更新，没有常驻服务。

Moodle 刷新规则由 AI 按对话边界执行：新对话或明确要求时完整采集，同线程后续消息复用已核验信息及原检查时间；没有定时器。网络调用共享4个并发槽，保持全部分页和正文读取。资料缓存以原文件完整哈希验证，不能用抽取成功代替视觉核验或学生掌握。

## 验收要求

重复初始化/升级保留旧状态；课程数量与名称不硬编码；学校写操作禁用；资料下载要求明确授权及限定模块，保留原件和哈希；凭据不出现在输出或版本库。新档案不含个人或演示作答。

题目、作答、曝光和复测关联一致；辅助回答不影响 FSRS；未答不是失败；重复调用不重复记录或加预算。跨日/状态变化能够检测过期视图，重建后恢复一致；未知耗时不变成0或重复求和。

考试来源改变或采集失败要求重新核读；未知题型不能出正式题型模拟；全范围模拟的助手题量安排明确可见；缺材料只出专项练习；待答页不泄露答案。原始数学条件与证明逻辑仍需人工/AI 审核，代码测试不能代替学科核验。

验证命令见 [TOOLS.md](TOOLS.md)。测试只使用隔离空白目录、虚构课程和模拟网络，不验证学校真实 SSO。真实浏览器登录涉及个人验证，未实际验证的路径应如实注明。发布前只选择通用文件，确认 Git 不包含个人状态、下载文件或凭据。
