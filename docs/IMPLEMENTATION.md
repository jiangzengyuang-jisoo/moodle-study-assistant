# 发布范围与验收

第一版面向 Windows，香港时区；沿用已在 HKU 使用的 Moodle API 采集、FSRS 和 SymPy，提供独立空白学习目录。新同学用自己的官方 API Token，浏览器登录方式另提供实验性 SSO 辅助。不包含作者课程、作答、日程或凭据。

实施顺序：通用配置及空白状态 → 本机认证和课程选择 → 只读工具及采集 → 中文入门文档 → 隔离安装和测试 → 检查发布文件 → 上传公开仓库。

验收：重复初始化不覆盖状态；可配置任意数量课程；禁止学校写操作及文件下载；凭据不出现在输出或版本库；真实作答才影响 FSRS；保留数学定义域；从空白目录完成依赖安装并通过测试。HKU 浏览器 SSO 涉及个人验证，未实际验证的登录路径应如实注明。
