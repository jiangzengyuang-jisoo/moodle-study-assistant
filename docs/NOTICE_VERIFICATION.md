# 考试与截止信息核对

适用于询问当前考试日期、时间、地点、范围、作业截止或据此排计划。普通章节教学不触发此流程。

## 先核读通知，再给确定结论

1. 确认学校、学期、课程、本人班级/组别和具体考试或作业。先利用现有选课记录，不把另一班、往年或不同轮次的安排套用给本人；关键身份仍不明才询问。
2. 本聊天首次回答该事项的当前安排时，在线核读相关课程的最新教师/授权助教公告、正文、编辑及必要回复，再与课程首页、大纲、日历、活动页面和本地记录对照。公共页与分班页均在相关范围内。仅找到旧日程、搜索摘要、最近若干条标题或成功下载课件，均不足以确认现行安排。
3. 搜索考试名称、班级及改期/更正线索，包含 changed、rescheduled、postponed 等；关键词只定位候选，不能替代原文。按需补足相关论坛分页，追到该事项原安排及后续变更，核读有意义的附件/图片。若分页、正文或附件不可读，明确缺口，不声称“没有改动”。不因此自动全科刷新、下载无关文件或后台监控。
4. 同一事项已完成上述核读、范围无缺口时，可在当前聊天后续追问复用，保留真实核对时间，不能说成重新联网。本人说“老师改了”、要求最新/重查，或出现相互矛盾的新证据时，必须重新查相关通知；这是同聊天复用的例外，不受章节回执或旧采集成功标记限制。先查通知，不要求本人反复证明旧记录过时。普通跨日或压缩本身不自动全量刷新。

## 判断哪一条适用

- 同一课程、班级和事项中，明确适用的后续教师更正覆盖旧安排；逐字段比较日期、开始/结束时间、时区、地点、范围和提交方式。只改时间不代表同时改地点或范围。
- 判断作者身份、适用对象和更正内容，不机械选最后更新时间：学生猜测、自动提醒、无关回复、旧帖无关编辑和其他班通知不能覆盖教师结论。保留原安排、新安排、发布日期/编辑时间、核读时间及原帖链接/ID。
- 教师新通知与活动页面冲突时，说明两者及各自来源，尤其区分“老师允许的期限”和“平台目前关闭时间”；无法判断时标待确认，不擅自认定平台已改或某来源永远更权威。
- 缺时刻不补 23:59，缺考场不套用平时教室，缺范围不套用上次考试。只有老师明确说沿用时才复用对应字段；日期和星期用实际学期/年份核对。

## 回复与保存

- 核实成功：先给适用于本人的日期、起止时间及时区，附直接通知链接；有改动时写清“旧安排 → 新安排”，必要时补地点或范围。此前答错则直接更正，不把未核实的推测说成教师安排。
- 联网失败、来源缺失或冲突未解：开头明确 **“最新安排尚未确认”**。若确有参考价值，随后才列“上次核实的旧安排（核对日期）”；不能先突出确定时间、末尾再加免责语。不能说“未发现变化”“应该还是原时间”或把失败记成核验成功。按本端已有连接恢复与授权规则处理，不循环重试、不绕过权限。
- 核实变更后，按本端现有安全写入入口更新对应任务/截止/考试记录和可重建视图；重读最新状态，保留旧值和变更依据，回读验证后才能报告已保存。局部核读只更新该事项的证据，不推进全科审阅基线、不调用要求完整快照的 exam-sync。接口只支持完整快照核读时，不伪造快照；先交付已确认结论并说明保存是否完成。不得为写记录而覆盖无关学习进度或原答。

## 规则核读情境

以下为文档验收情境，不是模型端到端测试或正确率承诺：

- 旧首页为 18:00，新教师通知仅将本班开始时间改为 17:55：答新时间，说明提前 5 分钟，其他字段只按明确证据保留。
- 更晚的另一班通知或学生回复：不覆盖本班教师安排。
- 同聊天先前核对过，但本人指出改期：重新核读相关通知，不沿用旧成功回执。
- 只能读到通知标题、前一页论坛或打不开附件：说明缺口，不宣称无变化。
- 连接失败：首句为“最新安排尚未确认”，旧安排明确标参考及历史核对时间。
- 教师延期而平台仍显示原关闭时间：同时报告冲突和提交风险，不声称平台已调整。
- 更正只涉及时间，未提考场：不能擅自改考场；更新记录保留旧值、来源与核读时间。
