# 教学前按来源时间同步本章课件

教学默认使用 `ensure-chapter`。新聊天先读取相关课程的云端目录，优先使用文件 `timemodified`，没有有效值时使用 `timecreated`。本地原件存在、内容未被本地修改、来源时间相同且阅读索引完整时，直接使用本地文件，**不为了比较远端字节重新下载**。这一策略无法检测老师改了内容却未更新时间的情况，不把时间一致说成远端字节一致。

## 默认流程

1. 先用 `study.cmd --chat "原始聊天ID" continue` 读取本地接续，再用本地 `context/search/outline` 确认课程、本章各部分及所需资料；不把一个搜索结果当作全章。
2. 执行 `study.cmd --chat "原始聊天ID" ensure-chapter --course 课程ID --chapter 章节`。本地没有 ID 也可执行，已有资料可重复附加 `--material ID`。明确章号按 Chapter/Ch/第几章匹配；名称不明确时由助手查相关课程目录并传 `--module 页面ID:模块ID`，不让用户手抄 ID。
3. 时间变化、本地原件缺失或旧档案尚无来源时间基线时，在已有课程级 full 授权内下载。缺本地时间基线允许一次下载建立，不能凭文件名、文件大小或本地修改时间补造基线。云端两种时间都未知时停止并报告 `remote_timestamp_unknown`，不冒充一致。
4. 下载成功后检查响应、内容、来源身份、本地原件完整性及全部选定资料的阅读索引。学校 HTTP 200 返回的 JSON 错误不能被当作 TXT 课件。同章明确资源未提供文件、来源被删除或改名、目录缺口均阻止教学就绪。
5. 本次同源更新的新文件完整可读后，删除本次替换的旧原件。旧 ID、来源、哈希、原页码、历史原答与删除状态保留；仅沿带教学更新标记的明确替代链清理失败重试留下的旧原件，先验证整链来源、哈希及路径；已删除或待删除节点可继续恢复，遇普通历史归档边界即停止。不追溯批量清理历史归档，不迁移新版掌握。本地批注或来源不匹配时保留文件并停止。新版索引失败时旧原件仍保留在事务归档；删除中断保留 deletion_pending 标记，可在处理原因后明确重试恢复。
6. 只有返回 `ready_for_teaching=true` 后，助手才能继续核读正文和原页并讲解。它只证明同步和索引可用，不证明助手已读完、学生已掌握。

同步失败、来源不明确或云端时间未知时暂停相关教学。按实际原因申请适用读取权限，登录/验证由本人处理；解决后使用原范围加 `--force` 明确重试。不改用通用知识或未同步本地旧版继续讲，不把权限问题误报为密码失效。

## 同一聊天和授权

- 同一原始聊天、同一范围、授权仍有效且本地文件/来源映射未变时，成功或失败回执可离线复用；保留原核对时间。跨日、压缩与重新打开不生成新聊天 ID。新聊天重新查相关云端目录。
- 新增所需资料会检查新增请求范围，已有来源时间一致的原件不会重复下载。用户明确重查才使用 `--force`；该参数重新查目录，仍不强制下载时间一致的文件。
- 已有 full 授权覆盖该学校、账号和仍选中课程页面后续新增资料，不逐文件、逐聊天重新索取下载许可。新学校/账号使用独立目录，不把相同数字课程号当作同一课程或版本来源。
- 主助手传原始用户聊天 ID；内部任务继承该 ID 并加 `--subtask`，只读接续，不触发章节同步。
- 同聊天复用时离线检查阅读索引，缺失/过期仅修复相关索引。缓存不可读或本地原件被修改则停止，不能因此自动再次下载覆盖批注。

回执保存在 `Study/_System/CourseContent/chapter-acquisitions/`，新策略为 version 2；升级前严格字节回执不能冒充时间基线。同源旧版的删除只发生在新策略明确标记的本次更新，不追溯处理已有历史归档。

## 显式严格诊断

`study.cmd --chat "原始聊天ID" verify-chapter --course 课程ID --chapter 章节 --material ID` 保留为显式诊断路径：它会下载并比较实际 SHA-256 字节，即使来源时间相同。普通教学不得自动改用此入口绕过默认不重下载策略。严格诊断的独立回执不代替默认时间策略，失败仍暂停教学。该路径继续保留历史归档，不执行教学默认的立即删除。

## 中断与边界

章节操作使用操作系统锁，进程退出后释放。`--force` 不绕过活跃锁。旧版遗留的普通 `.lock` 文件仍需确认旧操作已退出后再处理，不能按年龄批量清理。

本流程只查询相关课程目录和课件，不刷新全科公告、论坛、作业、日历，不推进全量审阅基线，不触发 exam-sync，不建立后台任务。首次选课的已授权完整初始化使用 `refresh`；`continue` 只读本地接续。计划、考试和最新通知仍按任务另行核对相关教师来源。


扫描课件同步与核读分开：PDF/图片没有文本时，工具逐页验证可渲染的原页，返回 visual_review_required 与 visual_units；这仍须助手实际看图。ready_for_teaching/teaching_ready 只表示资料可进入阅读流程，不代表已核读。同步成功后保存来源时间，同时间不重下载；原件损坏、原页无法渲染或纯空白材料仍阻断，不记成功。OCR不是同步前提，不凭OCR或渲染推断掌握。
