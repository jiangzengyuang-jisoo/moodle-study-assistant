## 迁入的学习功能

- 同一课程、题干、选项文本和来源页一致的题，即使更换复习条目、卷号或题号，也会检查此前的答案曝光。区分作答前后展示；补录较早的曝光时间不再直接视为重复。缺少来源或改写题干时不会猜测为同题，这不是语义相似度检测。
- 重复课表遵守 `applicable_from` / `term_end`，明确日期的补课保留。仅当日明确安排且有未完成证据的过期非考试任务继续列入优先项；已提交、小组已交及历史考试不重开。保留公开版的档案时区和字典/列表计划兼容。
- 考试来源索引记录图片与链接属性、附件/内嵌文件清单和编辑时间。论坛文字不变但这些信息变化时，原要求需要重新核读。旧记录尚未包含的媒体信息会在下次实际来源检查时触发核验；纯文本且没有新增元数据的哈希不变。它不会主动下载媒体来检测同链接、同元数据下的字节变化。

## 按需学校查询

MCP 新增 `moodle_get_calendar_events`、`moodle_get_grades`、`moodle_get_notifications`、`moodle_list_resources`、`moodle_get_site_info`，合计 15 个读取工具。保留原有完整论坛分页与正文工具。

- 日历默认未来 30 天，可指定课程与 Unix 时间范围 `timeFrom/timeTo`。优先使用学校提供的课程接口，否则分页后筛选课程；按事件游标读取，整个请求保持相同时间窗口。默认每页 50 条、最多 20 页，可限定 `pageSize`（1–50）和 `maxPages`（1–100）。分页不前进或达到上限返回 `complete:false`，应缩小时间范围继续查，不能把部分结果当成全部。完整性只指所选 API 和时间范围，不等于所有类型的学校事件，更不等于 AI 已核读。
- 通知支持 `limit/offset`；`has_more` 与 `next_offset` 表示后续页。后续单页不会冒充完整历史，读取不会标记已读。
- 成绩只查询当前账号；资料入口只列可见资源模块的元数据，不下载文件、不增加课程内容授权。站点信息只返回必要身份与能力字段。
- 新方法仍经过 `ReadOnlyClient` 的白名单、保留参数保护与拒绝重定向。没有新增作业提交、发帖、通知标记或下载 MCP 入口。接口未启用时明确返回不可用，不把它当作无数据。

分页参数按 Moodle 官方接口定义实现：[日历 API](https://github.com/moodle/moodle/blob/MOODLE_405_STABLE/calendar/externallib.php)、[通知 API](https://github.com/moodle/moodle/blob/MOODLE_405_STABLE/message/output/popup/externallib.php)。
