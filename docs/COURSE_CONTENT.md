# 选课后自动准备课程资料

> DeepSeek 分支的新选课流程采用 [课程资料库初始化](COURSE_LIBRARY.md)。本文的账户绑定授权与 `CourseContent` 报告继续兼容旧档案；新授权优先，选择“只同步信息”后不会回退到旧的下载授权。正常刷新通过统一入口调用对应资料同步，新流程报告位于 `Study/_System/LibrarySync/`。

双击 `choose-courses.cmd`，选择课程后再选择同步方式：

- **1 完整初始化**：一次授权这些课程，立即采集课程信息，下载接口可访问的课程资料，按课程归档并建立检索索引。后续正常刷新自动补齐新增或变更文件，不再逐个询问。
- **2 仅同步信息**：采集课程页、作业目录、公告与讨论等信息，不批量下载附件；同一范围旧的完整授权改为仅信息，已下载资料保留。
- 回车取消：不保存这次选课与授权。

已有用户也通过 `choose-courses.cmd` 确认当前课程和方式。更新代码不会默认为旧课程授权。授权保存在 `settings.course_content_sync`，绑定学校地址、当前账号和具体课程页；换账号、换学校或增加课程不会继承其他范围的授权。公共页与班级页都需要选中。

完整初始化处理课程资源与文件夹、作业说明及附件、论坛所有可访问帖子与附件、正文图片和接口返回的页面内容；保留课程页、活动、帖子和文件来源。文件按 Lectures、Tutorials、Assignments、Practice、Other 分类；不能可靠判断的先放 Other。原文件名不变，不同来源同名文件隔离，同内容按课程复用并记录多个出处。来源更新通过原有版本机制保留历史引用，不覆盖本地修改的原件，不因课程授权而启用归档删除。

大型文件流式保存，不需要一次放入内存。课程之外的外链只保留地址；学校未开放的页面、隐藏模块、交互内容与受保护的流媒体不能保证完整下载，会列出缺口，不尝试绕过限制。压缩包、音视频等可以保存，但不承诺全文索引或自动解包。

## 查看结果与补齐

日常仍用 `study.cmd --chat "当前聊天ID" continue`；同聊天复用结果，不重复全量下载。明确更新或重试时用 `refresh`。每次真实采集之后，资料阶段使用当前有效授权处理文件；采集快照保持原样，资料失败不撤销已经成功采集的证据。

`Study/_System/CourseContent/latest.json` 分开记录文件、保存的页面、索引和失败项；`manifest.json` 是可重建的下载检查点。`complete` 表示本次可枚举范围下载与索引没有已知缺口；`partial` 表示尚有失败、权限或解析缺口；`not_authorized` 表示没有匹配的完整授权。即使 complete，`reviewed` 仍为 false，必须实际核读内容后才可称已核验。

需要只补资料时，让助手从 `study.cmd ... status` 取得当前有效独立快照，再运行：

```powershell
node tools/moodle/run.mjs content-sync --snapshot "入口返回的独立快照路径"
```

该入口校验快照、学校账号、当前课程与授权。快照已过期或范围变化时先明确刷新，不修改旧快照来绕过校验。已有文件按来源版本和本地哈希复用；没有可靠修改时间的来源重新核对下载；失败项下次可重试。下载完成而索引失败的文件保留，补建索引无需重下已验证的文件。

索引只是检索入口：图片、扫描件、公式和排版仍需查看原页。不因下载、解析、提交状态或课件覆盖而增加掌握程度、复习评分或学习进度。没有后台同步，也不会提交作业、开始学校测验作答、发帖或修改学校完成状态。
