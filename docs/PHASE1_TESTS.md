## 本地接续性能

可运行 `python tools/study/benchmark_session.py` 重现。档案为 6 门虚构课程、231 条资料索引，没有实际 PDF 解析和历史错题负荷。

| 场景 | 本机测量 |
| --- | --- |
| 首次调用，包含人为设置的 250 毫秒采集等待 | 339.21 毫秒 |
| 同进程后续接续，20 次 | 中位数 3.00 毫秒；最大 10.81 毫秒 |
| 每次重新启动 Python 入口，10 次 | 中位数 118.90 毫秒；最大 128.38 毫秒 |
| 上述同一聊天的采集调用总数 | 1 次 |

这些结果证明该测试中的本地接续较轻、后续调用没有重复采集。**没有测量旧版与新版的真实聊天速度差，也不能把人为采集等待算作真实学校网络提速。** 冷启动、缓存、归档维护、网络与模型生成是不同成本，不给所有电脑承诺 0.5 秒。

## 仍需实际使用验证

不同客户端如何取得并传递原始聊天 ID、真实 Moodle 网络速度、完整学期档案规模下的耗时，以及 AI 是否认真核读来源。当前回执检查来源和提交过程，不评判教学内容质量；原页、图表和公式核验要求继续有效。

- 选课、章节与当前页推进、追加错题/更正说明正常；已有来源可补页码和核验详情，但不能改写原来源。
- 资料文件已移动、状态未落盘，以及状态已落盘、日志未清除两种中断，都在下一次正式写入前恢复；原件被修改时停止，不覆盖用户内容。

- 真实终止父进程后，子进程稍后落盘的有效快照可以被接续，不重新联网。
- 虚构密文字节通过 Windows DPAPI 实际解密测试，不接触真实账户凭据。

## 第二轮审计修复与独立回放

修复后全量回归通过 **295 项**：262 项学习工具测试、30 项 Node/API/桥接测试、3 项登录与加密测试。相较上一轮新增 30 项测试。

本轮针对当前题作答保留及旧考试来源跨入口回写补充测试：

- 四种当前题别名统一规则，含实际作答的题目不能未归档就清空或替换；原记录完整进入同课程 `checks` 后允许换题。
- 覆盖数字 0、布尔 False、显式空答案、部分作答、同题多次作答、多题列表、嵌套题目，以及未作答纯题面/标准答案不被误认成学生作答。
- 初次作答、补充核验信息和正常换题均允许；已有历史不能删除或改写，其他字段/其他课程不能冒充归档。
- `exam-sync/exam-profile`、其他带快照的日常入口、幂等重放及会话核读共用来源校验，旧轮次不能改写新规格；通用状态桥也不能绕过专用考试入口。

- 正向恢复回放：检查失败 → 明确刷新 → 重新登记考试要求 → 核读 → 完整模拟卷检查通过。

独立复核另外发现并修复了同一道题分次作答后归档时的编号冲突。再次回放确认，部分作答 → 完整作答 → 换题可以连续保存，两次原答均保留；历史删除、改写或重排被拒绝。上述测试范围内未发现剩余阻塞；这不代表已验证所有真实学校响应和客户端行为。
