## 本地接续性能

可运行 `python tools/study/benchmark_session.py` 重现。档案为 6 门虚构课程、231 条资料索引，没有实际 PDF 解析和历史错题负荷。

| 场景 | 本机测量 |
| --- | --- |
| 首次调用，包含人为设置的 250 毫秒采集等待 | 339.21 毫秒 |
| 同进程后续接续，20 次 | 中位数 3.00 毫秒；最大 10.81 毫秒 |

## 本地审计修复回测

修复后全量回归通过 **265 项**：232 项学习工具测试、30 项 Node/API/桥接测试、3 项登录与加密测试。比初版增加 31 项测试，测试输入均为虚构档案与模拟学校响应。

审计确认初版测试未覆盖的边界后，补充了以下故障回归与正向用例：

- 只保留编号、清空嵌套详情、改写原答案/来源/FSRS、删除历史事件均被拒绝，状态不变化。
- 选课、章节与当前页推进、追加错题/更正说明正常；已有来源可补页码和核验详情，但不能改写原来源。
- 资料文件已移动、状态未落盘，以及状态已落盘、日志未清除两种中断，都在下一次正式写入前恢复；原件被修改时停止，不覆盖用户内容。
- 固定请求贯穿 Python 入口和实际 Node 采集器，保留已登记测验链接；采集中途换课不会改变本轮输入，错误范围和未绑定快照不能登记核读。
- 课程范围变化正确标待核读；失败刷新保留原考试证据并阻止直接出卷，重复接续不重复写入，旧轮次失败不污染新核读。
- 真实终止父进程后，子进程稍后落盘的有效快照可以被接续，不重新联网。
- 虚构密文字节通过 Windows DPAPI 实际解密测试，不接触真实账户凭据。

同条件比较修复前 `3b00f1d` 与修复后统一入口：每组 12 次、每次启动新 Python 进程，均已完成虚构来源核读。
