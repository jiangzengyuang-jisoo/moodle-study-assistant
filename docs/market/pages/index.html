1. 开始前准备

  • 一台 Windows 10/11 电脑（当前只支持 Windows）。
  • 已安装 DeepSeek Harness 桌面版；本试用版基于 0.2.2-rc.1 验证，包声明 engines.dsh: ^0.2.2-rc.1。
  • 你的学校 Moodle 账号能在浏览器里正常登录，且学校启用了 Moodle Mobile Web Service（具体权限由学校控制）。
  • 安装与首次设置需要联网；系统里有 Microsoft Edge 或 Google Chrome（连接学校时用来打开登录页）。

2. 在 DeepSeek Harness 中添加社区目录并安装

  1. 打开 DeepSeek Harness，点击左侧 Plugins（插件）页。
  2. 进入 Experimental plugins，开启 Custom plugin indexes（自定义插件索引）。
  3. 打开 Discover 标签页，点 Add index source。
  4. 粘贴本目录的索引地址：
    https://jiangzengyuang-jisoo.github.io/moodle-study-assistant/index.json
  5. 在 Discover 中找到条目「Moodle 学习助手（Windows 试用版）」，核对版本 0.6.0-trial.6、作者 jiangzengyuang-jisoo 与来源（npm）后安装。安装前会显示第三方插件信任提示，请阅读并自行确认后点 Install；确认插件开关为 On。

社区索引没有官方审核与签名。若条目显示的来源、版本或作者与上面不一致，请停止安装，回到本页或仓库核对。

该目录不会自动出现在所有人的 Discover 列表中，也不会自动更新：你需要自己开启实验性索引功能并手动添加地址。

3. 首次设置（在聊天里完成）

安装完成后，建议新开一个聊天，说：

“帮我设置 Moodle 学习助手”

助手会一步步引导，不需要一次记住全部：

  1. 选择资料位置：默认是「文档」文件夹下的 MoodleStudy，也可以选其他文件夹；以前用过本项目时可直接选原来的资料文件夹。
  2. 安装运行依赖：插件用 Harness 自带的 Python 建立私有运行环境，首次需要联网下载约 20 MB，通常 1–3 分钟。
  3. 连接学校账号：助手在这台电脑的浏览器里打开学校登录页，由你本人输入账号、密码和验证码；第一次连接还会安装登录组件（约 40 MB 下载）。
  4. 选择课程：按课程名称选择要跟踪的课程，助手不会替你选。
  5. 确认资料范围：完整资料同步，或只同步课程信息。
  6. 首次同步并完成设置：只有同步证据与你的账号、课程、资料范围匹配时才标记完成；同步中断、失败或只完成一部分时会说明每门课程的可用范围和剩余问题，重跑同步是增量的。

任何一步中断或失败，重新打开聊天说“继续设置”即可从当前进度继续，已有资料不会被删除。学校暂时连不上时，已保存在本机的资料、章节讲解和教学记录仍可使用。

4. 升级与回滚

  • 升级：在 Plugins 页卸载旧版，再安装新版（当前为 0.6.0-trial.6）；个人资料目录和运行支持目录默认保留，学习记录与资料不需要迁移。
  • 同一版本已经安装时直接重装会被拒绝，需要先卸载再安装。
  • 回滚：卸载新版、重新安装此前的试用包；个人资料目录保持不变。升级或回滚前建议先备份整个资料文件夹。
  • 升级后如果聊天里看不到学习工具，按提示重启一次 DeepSeek Harness，或让助手检查设置状态；不要删除资料目录。

5. 关键限制

  • 仅支持 Windows；学校登录依赖 Windows 凭据保护和系统 Edge/Chrome。
  • 需要你自己的学校 Moodle 账号；学校需启用 Moodle Mobile Web Service，部分接口和资料可能因权限无法读取。
  • 首次使用必须联网安装运行依赖（约 20 MB；连接学校时另有约 40 MB 登录组件）；网络受限时会失败，恢复网络后可重试。
  • 真实验证范围有限：2026-11-12 已用真实学校账号的已保存 Windows 加密凭据完成真实连接、真实增量资料同步、教学保存与重启接续验收（属 0.6.0-trial.4 历史验收，不代表当前条目版本）；真实 SSO/MFA 页面重新登录、桌面 UI 鼠标点击安装走查、其他学校/电脑/Windows 账户尚未验证，需要你在自己的环境确认。
  • DOCX/PPTX 资料没有页图，只能读取抽取的文字；公式、图表和扫描件应以 PDF 原页为准，OCR 结果可能有误。
  • 本地保存不等于离线推理：断网时只保证本机资料和本地教学记录可读，模型调用仍依赖 Harness 当前使用的模型服务。
  • 这是社区插件，非 DeepSeek 官方收录；不承诺进入官方推荐、不承诺出现在所有人的 Discover 中，也不承诺兼容未来的 DeepSeek Harness 版本。
  • 第三方插件没有官方审核与签名；安装即表示你信任并允许它以 Harness 的权限在本机运行。

6. 隐私与只读边界

  • 学校接口只读：不提交作业、不代替你作答学校测验、不发帖、不修改学校完成状态、不发邮件。
  • 密码、验证码只在学校网页由你本人输入；插件不读取浏览器 Cookie，不把 Token 写进聊天、日志或插件配置。
  • 登录结果用 Windows 自带的加密机制（DPAPI）保存在你选择的资料文件夹的 .private 目录，只对当前 Windows 用户可解密；不要打开或转发该目录。
  • 学习资料、配置和学习记录保存在你选择的资料文件夹；插件包本身不含个人数据，卸载插件默认保留资料目录。
  • 助手读取到的资料内容可能会发送给 DeepSeek Harness 当前使用的模型提供方用于生成回答；请遵守学校对课程资料的版权与使用要求。

7. 出问题时的恢复入口

  • 工具缺失或调用失败：在聊天里说“检查 Moodle 学习助手状态”。该检查使用 Harness 的 Host 工具 moodle_study_status，不依赖 MCP 学习工具本身，会读出资料位置、运行依赖、学校连接和下一步恢复动作。
  • 设置或学习工具状态异常：让助手调用设置状态工具 study_setup_status，它会指出当前真正要做的下一步（继续选课、修复依赖或重跑同步等）。
  • 学校暂时连不上 / 断网：已保存在本机的资料、章节讲解和教学记录仍可使用；涉及最新作业、公告或考试信息时，助手会明确说明“当前不是最新线上结果”。网络恢复后重试连接即可，不需要重新登录；只有登录失效才需要你本人重新连接学校。
  • 不要删除资料目录来“修复”问题；先备份，再按助手提示操作。
  • 反馈问题时请描述你做了什么、看到什么提示；不要粘贴密码、验证码、Token，也不要转发 .private 目录。
