# 统一上手入口与中文诊断

适用于公开版 0.4.0。双击项目根目录的 **start.cmd**。这是中文文字向导，学习对话仍在能操作本地项目的 AI 客户端中进行。

## 第一次打开

1. 下载并完整解压公开项目，不在压缩包里运行。
2. 双击 `start.cmd`。没有 Python 3.11 或更新版本时，入口会显示官方下载地址和安装提示；安装时勾选 Add Python to PATH，然后重新打开入口。缺少 Node.js 22 或更新版本时也会给出提示。
3. 选择 **1 继续下一步**。需要安装依赖时，会先说明内容并要求输入 Y；这一步需要联网，调用现有 setup.ps1，可能花几分钟。向导不会静默安装系统软件。
4. 按下一步提示连接学校。默认 HKU；其他学校先按新手指南修改 config.local.json 中的学校地址。可选 Edge、Chrome，或隐藏输入学校官方 Token；密码和 MFA 只在学校网页输入。
5. 继续选择需要跟踪的课程。公共课程页和个人班级页可能都需要选；取消选课不会清空原有记录。随后会显示**课程级资料授权范围**，请选择 `1` 完整初始化（同步课程信息 + 下载/归档/建立索引）、`2` 只同步课程信息（不下载资料）或 `0` 取消；确认后保存授权。完整初始化可直接复用 6 小时内的完整快照，否则先做一次只读采集。新增课程页面需要重新授权；详细规则见 [课程级资料授权与自动同步](COURSE_LIBRARY.md)。
6. 环境就绪后，向导显示可复制的学习开始说明。在 AI 客户端打开含 AGENTS.md 的项目文件夹，让 AI 按统一聊天入口采集、核读并接续。**不用先手动刷新一次再开新聊天刷新一次。**使用 DeepSeek Harness 桌面版时，按 [DSH.md](DSH.md) 运行一次配置合并并重启客户端；聊天身份会自动使用稳定会话 ID。课程资料的完整初始化和后续同步见 [COURSE_LIBRARY.md](COURSE_LIBRARY.md)。

退出后可以再次打开。向导根据当前文件判断进度，不另存一份安装状态，不自动重试失败步骤；已完成的登录和选课不会仅因重新打开而重复执行。已有用户仍可直接回到 AI 聊天学习，不需要每天先跑向导。

## 菜单

| 选择 | 行为 |
| --- | --- |
| 1 继续下一步 | 提示当前缺少的准备步骤；就绪时显示学习交接说明 |
| 2 本地诊断 | 检查环境、配置、档案、课程选择、本地客户端配置和学校检查记录；不联网，不解密凭据，不写学习记录 |
| 3 联网检查 | 主动验证一次学校 API 连接；不采集课程，不下载课件，不推进核读状态 |
| 4 学习注意事项 | 显示换聊天、保存、刷新、课件、独立作答和升级规则 |
| 5 重新连接学校 | 选择浏览器登录或官方 Token 方式；由本人操作 |
| 6 调整课程与资料授权 | 通过已有工具联网列出课程，由本人选择页面并确认课程级资料授权（完整初始化或只同步课程信息）；保留学习历史，新增课程需重新授权 |
| 7 安装或更新依赖 | 确认后运行现有安装流程；已有资料缓存同步可能耗时，归档维护仍遵循用户已授权的规则 |
| 0 退出 | 停止向导，没有后台任务 |

如果已有配置或档案损坏、时区不一致，或项目 Python 解释器不可用，向导会停止写入并提示先修复。已有档案却缺配置、档案缺失却仍有备份/运行记录时，也会要求先恢复，不按默认学校或空白档案重新初始化。不要删掉 Study 后重新初始化。缺少依赖可以补装；损坏的解释器需要单独修复。

向导和安装会共用可用的 Python 选择结果。环境建立中途退出、缺少 pip 时，下次选择安装会先用 Python 内置安装包离线恢复 pip，再继续依赖安装；恢复不触碰学习记录。若内置恢复失败，本次向导会转为环境修复提示。实际时区名称也会校验，不只是比较两处字符串是否相同；时区错误需核对后修复，不能自动平移历史日期。

## 单独运行诊断

双击 **diagnose.cmd**，只做本地检查。在 PowerShell 中也可以：

```powershell
.\diagnose.cmd -NoPause
.\diagnose.cmd -Online -NoPause
.\diagnose.cmd -Json -NoPause
```

`-Online` 是主动联网授权，只验证连接。`-Json` 输出结构化摘要，不自动保存或发送；可与 `-Online` 合用。缺少必要环境时不会强行联网。退出码 1 表示有未完成步骤或明确错误；提醒、尚未联网核验不等于安装失败。缺 Python 时只能提供启动阶段诊断。

同一次向导里已经验证过的连接结果，会在后续本地诊断中标为“此前检查”，保留原检查时间；本地检查不会把已知失败变成成功。明确重查会更新结果；学校地址或授权文件变化后旧结果失效，重新标为待验证。关闭向导后不保存这份临时结果，下次打开也不会自动联网，凭据存在仍不等于有效。

诊断只输出预设的检查结论和建议，不包含学校地址、姓名、课程正文、个人原答、授权内容或本机路径，也不回显底层异常。**菜单里登录和选课时的原始终端内容不属于可分享摘要**，不要直接整屏复制发到公开 Issue。

## 看懂不同状态

连接失败现在区分域名解析、超时、HTTPS 证书、HTTP 服务异常、访问权限、授权失效、异常响应及本机解密问题；诊断仍只输出固定提示。域名解析或网络失败不等于凭据失效，解密失败也应先核对原 Windows 用户及执行环境。其他已授权连接正常时，可通过客户端的授权机制重试同一只读检查；工具不会自行提权、关闭证书校验或绕过学校限制。没有新的成功结果就保留上次记录，不能宣称已修复所有网络环境。

部分接口失败会在独立采集快照中保留分类与恢复建议，仍标记为未完整采集，不自动重试或登记完整核读。

- **已发现本机加密授权**：只知道文件存在，不知道现在是否仍有效。
- **本次 API 连接验证成功**：刚验证了连接，不代表所有课程接口有权限或课程内容已更新。
- **已采集，待 AI 核读**：学校数据已拿到，仍需 AI 阅读与核对。
- **最近快照已有核读回执**：本地保存的那次核读可验证，不代表老师此后没有更新，也不能证明 AI 解释一定正确。
- **采集未结束/中断/失败**：回到原聊天查看并按需恢复；不创建新聊天不断重试。

本地客户端配置检查只能检查已保存的路径和格式，不能保证客户端已经加载工具或取得项目权限。自定义配置和移动项目后的路径由本人或 AI 核对，向导不覆盖它们。
