# AI 新手使用指南

本指南对应 `deepseek` 分支，安装只配置 DeepSeek Harness。

**推荐直接在 Harness 项目聊天里说“帮我安装并教我怎么用”。** 安装、选课和选择同步方式都在聊天中完成，学校登录在学校网页完成；结束后助手主动讲解并带你开始一次操作。中断后说“继续初始化”。详见[聊天上手](CHAT_ONBOARDING.md)。以下为本人选择手动设置时的备用说明。

## 先认识三个东西

**Moodle** 是学校网站，提供课程和作业信息。**本项目**是装在电脑上的小工具和规则，保存你的学习记录。**AI 客户端**负责理解作业、讲解和安排学习，需要能打开本地项目并使用工具。

“CLI”就是通过文字指令使用的程序。本项目提供双击入口，你不需要先学命令行。“MCP”是 AI 连接工具的方式；这里只连接你电脑上的只读 Moodle 工具。

GitHub 是存放公开代码的地方，不是你的学习记录存储服务。仅在浏览器打开这个 GitHub 页面，不会启动助手。

## 下载与安装

1. 在仓库首页点 **Code → Download ZIP**，右键压缩包，选择全部解压。
2. 把解压后的文件夹放到稳定位置，例如 `D:\MoodleStudy`，避免每次移动。Windows 路径包含空格或中文可以使用。
3. 从 [Node.js 官网](https://nodejs.org/) 安装 LTS 版本（22 或更新），保留默认的 npm 组件。
4. 从 [Python 官网](https://www.python.org/downloads/windows/) 安装 Python（3.11 或更新）。勾选 **Add Python to PATH**；安装后重新打开项目窗口。
5. 双击 `setup.cmd`。它只在项目内建立依赖环境、空白学习档案和 MCP 设置。首次联网下载可能需要几分钟。
6. 出现 `Setup complete` 后继续。若失败，不要只看最后的 `Press any key`；把出错的文字给 AI，说明是在安装哪一步。**不要发送 Token 或密码。**

重复运行安装会保留已有学习档案。更新项目代码前先单独备份 `Study/`；不要用另一份空白档案覆盖它。更换电脑应重新安装和登录，不复制凭据。

## 连接你自己的 Moodle

默认地址是 HKU Moodle。如果不是 HKU，用记事本打开安装生成的 `config.local.json`，把 `moodle_url` 改成学校 Moodle 首页地址，例如 `https://moodle.example.edu`。不要填课程链接或带登录参数的地址。学习时区默认香港；其他时区请让 AI 将 config.local.json 与已有 Study/_System/state.json 的 timezone 保持一致，使用 IANA 时区名称，例如 Europe/London。已保存的日期不应未经核对直接平移。

双击 `connect.cmd`，程序会打开一个临时 Edge 窗口。**在学校网页里自己输入账号、密码并完成 MFA**。如果学校要求确认启动移动服务，按页面完成确认。此窗口使用新的登录会话，不读取你原有浏览器的 Cookie。

成功时窗口关闭，终端显示“Moodle API 已验证并加密保存”。这是使用 Moodle 官方移动授权取得 Token，之后普通刷新使用 Token，不要求每天重新输入密码。工具不会保存学校密码，也不会把 Token 显示在对话中。若授权过期或被学校撤销，重新运行连接即可；无法保证永久有效。

**兼容性说明：**核心 API 采集在 HKU 实际使用过。这个面向新用户的浏览器登录辅助是首版实验功能，已做模拟回调验证，但不能代替每所学校真实 SSO/MFA 的端到端验证。学校禁用移动服务、强制其他登录流程或特殊确认页时，可能需要下面的备用方式。

### 连接失败或已有官方 Token

- 没安装 Edge 但有 Chrome：在文件夹地址栏输入 `powershell` 回车，输入 `./connect.cmd --browser chrome`。
- 已有学校官方提供的 Moodle Web Service Token：同样打开 PowerShell，输入 `./connect.cmd --manual`，在终端隐藏输入处粘贴。**不要粘到 AI 聊天中。**
- 部分学校会在 Moodle 的“偏好设置 → 安全密钥 / Security keys”提供管理入口，常见路径为 `/user/managetoken.php`。并非每所学校都提供，找不到时不要猜 Token，也不要让 AI 抓浏览器 Cookie；向学校 IT 确认官方移动服务/API 权限。
- `invalidtoken`：Token 失效、错误或对应学校地址不一致，重新连接。
- API 权限不足：只能读取学校开放的部分，保持其他记录为待确认。不要提交密码给第三方“解锁”服务。

## 选择课程并首次刷新

双击 `choose-courses.cmd`（或 start.cmd 第 6 项），窗口列出你有权访问的课程。只输入这学期要跟踪的课程数字 ID，用逗号分隔。例如示例 `101,102`，以自己窗口实际显示的数字为准。不要照抄别人的 ID。

同一科的公共课程页和个人班级页可能各有一条，应该都选择。选好页面后会显示**课程级资料授权范围**：选 `1` 完整初始化会同步课程信息，并下载、归档、建立索引当前账号可直接访问的资料；选 `2` 只同步课程信息，不下载资料；选 `0` 取消。确认后保存授权，之后日常同步沿用授权增量补齐，不再逐份询问；新增课程页面需要重新授权。详见[课程级资料授权与自动同步](COURSE_LIBRARY.md)。

选课并保存授权后，可直接让 AI 在新聊天中使用统一入口采集并核读，不需要先手动采集一次。需要手动刷新时才双击 `refresh.cmd`；它采集作业、在线练习、论坛和日历，建立独立轮次并保留兼容的 `Study/_System/refresh-latest.json`，普通刷新本身不下载附件。AI 核读使用入口返回的独立快照路径；下载或解析成功不等于已核读或已掌握。

- `collection_complete: true`：配置范围内 API 采集完成，下一步让 AI 阅读。
- `collection_complete: false`：至少一部分失败；本次结果与错误仍保留，上次完整采集不覆盖。让 AI 说明哪些未更新。
- `reviewed: false`：正常。这表示“采集好了，还没有经过 AI 核读”，不代表登录失败。

## 让 AI 使用这套工具

1. 在 DeepSeek Harness 桌面版打开含 `AGENTS.md` 的项目根目录。
2. 运行本分支的 `setup.cmd`，它只合并 Harness 配置并写备份，不生成 Codex 配置。
3. 完全退出并重启 Harness；选择需要的 DeepSeek 模型，新建聊天，实际加载 self-study-tutor 并调用 Moodle 只读工具。
4. 同一聊天重开后核对身份仍一致。配置可解析不等于实际运行成功。
5. 移动项目或同名配置冲突时，按 [DSH.md](DSH.md) 核对再更新路径；不要删除其他设置或学习档案。

向导不会自动更换模型或读取密码、验证码。桌面图片上传等能力以实际验收为准。教学、资料下载与记忆规则见根 AGENTS.md。

## 首次告诉 AI 什么

不要一次写一大段复杂 prompt。用自然语言说明：

- 哪些作业已交、哪些纸面做完但未交、小组是否由同伴代交。
- 每门课实际学过哪里，以及仍不理解的内容。学过不自动等于掌握。
- 真实课表、固定活动和最近可用学习时间。
- 课件可由已保存的课程级完整授权自动同步；也可以把自己希望使用的课件/PDF/题目放入 `Study/_Inbox/`，提醒 AI 整理。原始资料保留，普通刷新不自动下载附件。

AI 应生成今天的初步计划，指出当前作业对应章节，并列出少量待确认事项。你没有提供的数据应保持未知，不应一上来把所有作业写成“未开始”。

## 日常对话例子

每个新对话开始时检查一次 Moodle，同一对话连续追问使用已核验结果。需要中途更新时直接说“刷新 Moodle”或“查最新情况”；切换课程、跨日、压缩上下文和重新打开旧对话不会自动再查，也没有后台轮询。学校在上次检查后发布的内容，要到下一次刷新才会发现。

初次归档并登记课件后，让 AI 建立资料缓存；以后复习只按需要读取完整原页。新增或修改文件时才重建对应缓存，进度和错题继续保存在原档案。详细入口见 [资料缓存与快速启动](LIBRARY.md)。

```text
看看 Moodle 今天有什么变化。我今天只有 90 分钟，先安排最重要的任务。
```

```text
开始今天的会计。用老师课件的方法讲，先解释，再让我自己做一道。
```

```text
这一步为什么这样算？我没懂，请换一个更简单的例子。
```

```text
我已经提交这份作业。小组项目由组员代交，不要因我个人没记录再安排一次。
```

```text
开始 15 分钟复习。先不要给答案，等我独立答完再更新复习时间。
```

工具用 FSRS 计算复习间隔，但“听懂了”“看了答案”不是独立作答。不能为了生成计划假造练习记录。SymPy 可以辅助核验计算，复杂证明仍须根据题设逐步检查。

```text
今天做完练习前两题，用了 25 分钟，卡在如何选择公式。请记录反馈，下一次从这里继续。
```

```text
帮我检查考前还有哪些知识点没独立做过题，并复盘这一周最需要改进的地方。
```

第一次使用没有个人题库，需要 AI 先根据实际材料准备核验过的复习题。当天再次对话会继续使用同一复习预算，不会再追加一整段。跨日或记录变化后，AI 会重建并检查计划；关闭项目时文件不会自行更新。

## 按老师题型出模拟卷

已保存课程级完整授权时，相关课件会由资料同步自动获取并归档；也可以把相关课件放进 `Study/_Inbox/`，或明确说“从 Moodle 下载某门课的第几章课件”。助手只获取授权范围或你指定范围内的资源，保留原名和来源，核读后归档；普通刷新不会自动下载。

接着可以说：

```text
读取老师在 Moodle 上对这次考试的说明，按公布的范围和题型出一套模拟卷。
依据我提供的课件，先给题目，不给答案；没有公布的题数或分值要明确标注。
```

AI 会核对是否是当前班别和本次考试，把老师已确认的要求与练习安排分开。若老师已确认范围、时长和各题型分值，但没有公布长题数量，可以出全范围卷并标出助手安排的题量；若缺某章课件，则先说明缺口，不能把现有专项练习称作完整卷。连题型都没公布时，不能承诺按正式题型出卷。

准备好后打开 `Study/_System/Mock Exams.md`，再进入课程试卷。答完可以把文字、手写照片或文件交给 AI，说“批改这份模拟卷”。只做了一部分就批改这一部分，不把未答题冒充零分记录。看答案或接受讲解后，同一道题的重复回答不会当作新的独立掌握证据；需要换变式复测。

`Exam Coverage.md` 显示已登记考点的材料和独立作答缺口，`Weekly Reflection.md` 显示最近7天真实反馈。数据不足会明确说明，不会凭“提交了作业”宣布已经学会。模拟卷是练习，不是学校真题或成绩预测。

## 从旧版更新

先看[更新日志](../CHANGELOG.md)，了解自己当前版本之后新增了什么、修复了什么，以及哪些功能需要另外启用。更新公开代码不会自动发生，需在你自己的项目文件夹里完成。

1. 暂停正在修改学习档案的对话，在本地安全位置备份 `Study/` 和 `config.local.json`。不要用另一份空白档案或别人的记录覆盖它。
2. **用 ZIP 安装的同学：**重新下载并解压到临时文件夹，将里面的公开代码和说明复制到原项目文件夹，覆盖同名程序文件；保留原来的 `Study/`、`.private/`、`config.local.json` 和 `.codex/`，不要先删除原项目。自己改过的规则或代码先请助手比较合并。
3. **用 Git 安装的同学：**让助手检查本地改动，再拉取更新；有冲突时先合并，不用强制重置丢掉改动。
4. 在原项目中重新运行 `setup.cmd`，更新依赖并为已登记资料建立缓存。已有学习档案会保留。
5. 让助手读取新版规则，重建并检查当前计划，再确认之前的学习位置和错题仍在。

整个升级过程都在原项目内继续使用已有授权；不要显示或分享 `.private/` 中的凭据。换电脑仍须重新安装和登录。

更新后让 AI 读取新版规则，运行当前计划重建与检查；将旧档案中“每条消息刷新”的默认设置同步为“新对话开始或明确要求时刷新”，保留你另行明确指定的偏好。首次为已登记资料运行 `tools/study/library.cmd sync`；这是可重建缓存，不会重置学习记录。新增的覆盖检查只使用有明确考点对应关系的记录；以前没有这类映射时显示“未独立测试”，不表示你过去没有学习。

想使用新版资料归档功能，可以对助手说：“核对已有资料的新旧版本，日常只用最新版，保留进度和错题引用；旧版保留 30 天，使用时检查，仅清理无引用、无本地修改且新版可验证的归档。”清理需要你明确同意，不会因更新代码自动开启；具体规则见[资料版本管理](MATERIAL_VERSIONS.md)。

## 退出、备份与分享

关闭 AI 项目即可结束本次学习；不会在后台继续轮询或发邮件。你的记录在 `Study/`，备份时自己妥善保存。学校页面或客户端聊天里看到的学习内容不自动公开到 GitHub。

给同学发 GitHub 仓库链接，让他们自己下载、登录和建档。**不要分享自己使用后的整个目录、`.private/`、`Study/` 或 `config.local.json`。** Git 的忽略规则不能阻止你手动压缩、网盘同步或强制添加文件。

遇到问题时，把“做到哪一步＋错误文字”给 AI。若发 GitHub Issue，先删掉姓名、学号、课程讨论正文和路径中的个人信息；不要附凭据或完整学习状态。


## 聊天入口升级

2026-10-31 起，AI 可按 [统一入口说明](SESSION.md) 使用 `study.cmd`。第一次聊天检查学校信息，后续继续聊天复用；你明确要求更新时再刷新。出错时先看状态，保留原聊天标识和操作编号，不需要重建档案。升级代码后仍保留原有 Study、.private、config.local.json 和 .codex。
