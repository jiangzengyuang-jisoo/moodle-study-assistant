# 开始学习前的一页说明

这份说明适用于给同学使用的公开版。首次可在 start.cmd 中选择“学习注意事项”；不需要记住所有工具命令。

## 聊天怎么分

| 场景 | 建议 |
| --- | --- |
| 同一道题追问、同一知识点继续练习 | 留在原聊天，保留完整推理过程 |
| 换课程，或开始独立的新章节/任务 | 可以在同一学习项目里新建聊天，方便聚焦 |
| 一段聊天很长且混入许多无关任务 | 先保存接续，再新建聊天 |
| 发生上下文压缩 | 不必立即重开；若接续不准确，先让 AI 重读学习记录和原题 |

新建聊天不是新建项目，不用重新安装或建档。上下文压缩用于缩小长对话的上下文并保留继续所需的状态；不是开始学新知识就必然触发，也不能直接等同于“所有记录丢失”。详见 [OpenAI 的上下文压缩说明](https://developers.openai.com/api/docs/guides/compaction)。不同客户端的提示与行为可能不同，本项目不保证自动发现上下文已满。

## 换聊天与结束学习

结束前可以说：“保存我实际学到的位置、原始作答、卡点和下一步，告诉我是否保存成功。”重要作答、错题和进度应及时保存，不等聊天快满才统一处理；没有新学习证据的普通追问无需反复重建计划。

新聊天开始可以说：“读取这个项目的学习记录，继续我的〔课程/章节〕，先确认上次停在哪里。”不要假定新聊天拥有上一段对话的全部内容。助手应从持久记录和原资料恢复，不只凭聊天记忆。不要同时在两段聊天修改同一学习任务；遇到保存冲突先让助手读取最新版合并。

## 老师刚发了内容怎么办

教学前只核对当前章节要用的课件，下载实际内容与本地比较；同一聊天继续学时复用结果，新增所需课件才检查新增部分。做计划或问最新通知时，只查询相关学校信息；明确要求完整检查时才全量刷新。核对失败会说明“本次未核实更新”，可先用本地版本继续，不反复自动重试。无关问答、连接维修不启动教学检查；没有后台轮询，跨日、压缩或重开同一聊天不重复检查。

每学一个小概念就开新聊天，可能反而增加重复采集的等待。诊断中的“连接成功”、采集成功和 AI 已核读是不同状态；失败时旧信息只代表上一次成功检查。

## 资料与学习质量

- 选课时可一次授权完整初始化，随后自动下载、归档与索引授权课程资料；也可仅同步信息或把课件放入 Study/_Inbox。下载和索引不等于已核读。
- 告诉助手具体课程、章节、题目或页码。整章复习先核对目录和范围，不能把少数搜索结果当成全章。
- 公式、图表和完整题设要核对原页；抽取到文字不等于解析正确。老师的说明、同学猜测与 AI 推断应区分。
- 独立尝试时先保留自己的原答，再请求提示。看过答案、提示后答对或自报完成，不算独立掌握；请告诉助手实际接受过哪些帮助。
- 普通复习使用已确认的最新版资料。追查旧错题时说明需要原版本，不能拿新课件页码替换历史引用。

## 遇到等待或错误

首次安装、首次解析资料、学校采集和 AI 生成都有可能花时间。先看目前在哪一步；不要连续重复点击安装或刷新。诊断只检查工具与保存状态，不能测出所有 AI 生成耗时，也不能保证教学结论正确。

用 diagnose.cmd 查看中文摘要。需要确认学校连接时主动选择联网检查；授权失效就由本人重新登录。仍有问题时，提供版本、发生步骤和诊断摘要，不发整个学习文件夹、密码、Token 或真实题目原答。原始终端内容应自行检查后再分享。

## 升级与隐私

升级前暂停写入并备份 Study/ 和 config.local.json，保留 Study/、.private/、config.local.json 和 .codex/；自己改过的代码先比较合并。不要删除旧文件夹后用空白版本替代。换电脑或换 Windows 账户应重新登录，不复制凭据。具体见[升级步骤](新手使用指南.md#从旧版更新)。

给别人分享公开仓库链接，不分享自己使用后的整个目录。学习文件保存在本地，但交给 AI 读取的内容可能发送给模型服务商；本地保存不等于离线推理。

老师要求、截止日期和重要答案有疑点时，回到官方信息与原资料核对。助手不会替你提交作业、发帖或修改学校完成状态。
