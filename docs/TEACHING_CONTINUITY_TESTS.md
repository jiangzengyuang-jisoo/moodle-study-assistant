## 本轮六类缺陷的复现与修复

| 缺陷 | 已验证结果 |
| --- | --- |
| 从答案键或子题绕过原答条件 | 拒绝答案键、评分/反馈容器、只有历史的汇总；子题继承父题已知帮助/曝光，未知父条件及其他子题的帮助不误伤独立作答 |
| 知识点和复测时间可借用 | 明确主题不符、旧答改日期、缺少真实通过结果、同答冒充两次复测均被拒绝；独立答错仍可保留为独立表现 |
| 真实复习记录漏查 | 实际 prepare → record_attempt → evidence/context → 保存观察链路通过；旧记录不用补写 course_id，多课程、重复标识及冲突不会猜测归属 |
| 归档后观察指向新题 | pending → checks、课程顺序变化后仍解析原答；相同子答案但父题不同也能区分；原答内容及父题身份都有绑定，旧观察未绑定显示待核实 |
| 原答类型与内容保护不严 | 0/False、1/True、空答和结构化原答不可改写或扩写，既有错答评价不能改正确；追加注释、子题、后补评分和首次填写未知答案仍可正常保存 |
| 旧字典历史无法转章 | 旧 history 字典及旧活动游标完整保留后可转章、继续再转章；丢失/改写旧数据或缺少原答归档会被拒绝，无关保存维持旧格式 |

三个独立复审方向交叉检查了证据判断、课程查询与保存保护，并回放新发现的评分容器绕过、原生曝光字段、同答复测、子题错指、评价覆盖和结构化答案扩写；修复后具体复现均通过。实际保存测试确认拒绝时状态、上一版本备份和原资料字节不变；合法保存保留旧错题及材料 ID/页码引用。只读 evidence-source 命令前后虚构档案目录字节一致。

最终日志在公开版忽略目录 `tmp/teaching-fixes-study/final-regression.log`、`tmp/teaching-fixes-entry/final-regression.log`、`tmp/teaching-fixes-node/final-regression.log`。学习工具 42.325 秒、上手等 49.215 秒、Node 1.386 秒；这是本机测试耗时，不是模型教学速度或实际用户体验结论。更新日志与使用规则已同步，Git 差异检查通过。本轮只更新公开版代码、规则、测试和文档，不修改个人档案，不推送 GitHub。

## 已验证行为

- 当前章节为新章，历史检查/旧游标包含更晚时间的旧题、handoff 和 next_step 时，接续只返回活动位置。
- 切换 topic/chapter 前必须完整保留旧活动位置；已有原答（包括 0/False）仍须保留在 checks 或当前题，历史快照不能绕过原答保护。
- 覆盖核对与知识观察独立保存；讲解、自述经历、辅助完成不能被新观察升级为独立证据。新增独立/延迟观察需原答引用和条件核验，更正通过追加记录保存。
- 查询可以找到旧章节及长笔记中的概念，区分结构化等级和旧文本候选；未命中不返回“未学过”。同课程过滤、别名、截断和答案隐藏有回归覆盖。
- 独立进程在中文路径执行 evidence，前后虚构档案目录所有文件字节一致，没有计时或归档维护写入。
- 原有保存、冲突恢复、资料引用及上手入口测试继续回归。直接调用 library.py 时统一 UTF-8 输出，避免 Windows 默认编码破坏中文 JSON。

## 教学行为验收边界

规则明确要求：仅上传作业先处理当前意图；先查跨章经历再判断缺口；覆盖结论限定课件图表、作业和历史共同核对的范围；用户纠正“以前讲过”后调整安排但不判掌握；推进时更新当前游标、保留旧章待复习。

这些自然语言教学判断没有在本轮通过真实模型对话验证。自动化测试验证的是路由、查询和保存约束，不能保证模型始终遵循规则，也不能证明教学质量或课堂覆盖事实。下一次公开版实际试用需用上述场景验证，特别保留图表原页核读及无提示新题证据。

## 复现

```powershell
.venv/Scripts/python.exe -B -m unittest discover -s tools/study -p 'test_*.py'
.venv/Scripts/python.exe -B -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.mjs
```

若系统临时目录不可写，将当前进程 TEMP/TMP 指向项目内专用的 tmp 子目录再运行；这些测试均使用隔离的虚构档案。

升级只更新代码/规则，保留 Study、凭据及本机配置；不批量修订历史判断。旧游标与长笔记矛盾时由助手核对原记录后保存，不自动从最后一条笔记猜测位置。
