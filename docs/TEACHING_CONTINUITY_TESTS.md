# 教学接续与跨章节证据回归

范围：公开版基于 0.3.1 的教学接续修复。全部使用虚构档案，不读取或修改作者个人学习记录，不访问真实学校或模型 API。

最终回测 **371 项通过**：300 项学习工具、41 项上手/诊断/登录、30 项 Node/API/桥接；相对原 333 项新增 38 项（12 项教学接续、11 项历史查询、15 项来源保护）。Windows 安装恢复与 DPAPI 测试实际运行。技能格式及 Git 差异空白检查通过。

首轮发现并修正中文 stdout 编码、旧 history 结构兼容、过长观察摘要以及原答引用校验问题。系统受限临时目录导致部分安装/登录测试无法写入，改用公开版被忽略的 `tmp/teaching-tests` 后完整通过；未降低断言或跳过测试。详细本地日志位于该临时目录，不进入公开提交。

## 已验证行为

- 当前章节为新章，历史检查/旧游标包含更晚时间的旧题、handoff 和 next_step 时，接续只返回活动位置。
- 切换 topic/chapter 前必须完整保留旧活动位置；已有原答（包括 0/False）仍须保留在 checks 或当前题，历史快照不能绕过原答保护。
- 覆盖核对与知识观察独立保存；讲解、自述经历、辅助完成不能被新观察升级为独立证据。新增独立/延迟观察需原答引用和条件核验，更正通过追加记录保存。
- 查询可以找到旧章节及长笔记中的概念，区分结构化等级和旧文本候选；未命中不返回“未学过”。同课程过滤、别名、截断和答案隐藏有回归覆盖。
- 独立进程在中文路径执行 evidence，前后虚构档案目录所有文件字节一致，没有计时或归档维护写入。
- 原有保存、冲突恢复、资料引用及上手入口测试继续回归。直接调用 library.py 时统一 UTF-8 输出，避免 Windows 默认编码破坏中文 JSON。

## 教学行为验收边界

规则明确要求：仅上传作业先处理当前意图；先查跨章经历再判断缺口；覆盖结论限定课件图表、作业和历史共同核对的范围；用户纠正“以前讲过”后调整安排但不判掌握；推进时更新当前游标、保留旧章待复习。

这些自然语言教学判断没有在本轮通过真实模型对话验证。自动化测试验证的是路由、查询和保存约束，不能保证模型始终遵循规则，也不能证明教学质量或课堂覆盖事实。下一次公开版实际试用需用上述场景验证，特别保留图表原页核读及无提示新题证据。

## 复现

```powershell
.venv/Scripts/python.exe -B -m unittest discover -s tools/study -p 'test_*.py'
.venv/Scripts/python.exe -B -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.mjs
```

若系统临时目录不可写，将当前进程 TEMP/TMP 指向项目内专用的 tmp 子目录再运行；这些测试均使用隔离的虚构档案。

升级只更新代码/规则，保留 Study、凭据及本机配置；不批量修订历史判断。旧游标与长笔记矛盾时由助手核对原记录后保存，不自动从最后一条笔记猜测位置。
