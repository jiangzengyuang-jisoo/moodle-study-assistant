## 历史通用操作说明（原文保留）

以下保留早期试用说明及当时的版本、验证范围；其中旧包名不是当前安装目标。通用界面步骤可参考，具体候选始终以上文为准，旧验证不计作 trial.8 的重测。

适用版本：DeepSeek Harness 插件包 `dsh-moodle-study@0.6.0-trial.6`（试用版）。本说明面向第一次使用的同学，不需要编程或命令行基础。更新时间：2026-11-13（香港时间）。

Moodle 学习助手安装到 DeepSeek Harness 后，你可以在聊天里学习自己电脑上的课程资料：按章节讲解、复习、核对本章文件、记录学习位置，并在需要时读取学校最新的作业要求和公告。学校接口**只读**——不提交作业、不代替你作答学校测验、不发帖、不修改学校完成状态。

## 1. 开始前需要准备什么

- 一台 **Windows** 电脑（当前只支持 Windows）。
- 已安装 **DeepSeek Harness 桌面版**（本试用版的构建与本地功能在 0.2.2-rc.1 上验证；真实学校登录与同步仍需你本人完成，见第 9 节）。
- 你的学校 **Moodle 账号**能在浏览器里正常登录（学校需要启用 Moodle Mobile Web Service，具体权限由学校控制）。
- 安装和首次设置需要**联网**；之后学习时只在需要学校新信息时联网。
- 系统里有 **Microsoft Edge 或 Google Chrome**（连接学校时用来打开登录页）。

> 提示：插件是第三方代码，安装时会显示第三方信任提示；安装即表示你信任并允许它以 Harness 的权限在本机运行。本插件不会执行任意命令，也不会把资料上传到本项目仓库。

## 2. 安装插件（3 步）

1. 打开 DeepSeek Harness，点击左侧 **Plugins**（插件）页。
2. 点 **Add plugin**，粘贴试用包文件夹的绝对路径（或 `.tgz` 文件的路径）。例如把试用包解压到 `D:\MoodleStudyPlugin`，就粘贴这个文件夹路径。
3. 阅读第三方插件提示，点 **Install**，等待安装完成；确认插件开关为 **On**。

安装完成后，建议**新开一个聊天**，再开始首次设置。如果安装时出现要求允许依赖构建脚本的提示（`Allow these scripts and retry`），本插件不需要额外依赖，正常不会出现；若出现可按提示允许后重试，或把界面文字反馈给发布者。

> 同一个插件包已经装过时，直接再装会被拒绝；需要先在 Plugins 页卸载旧版，再安装新版。

## 3. 首次设置（6 步）

在聊天里说 **“帮我设置 Moodle 学习助手”**，助手会一步步引导。每一步完成后再进行下一步，不需要一次记住全部。

1. **选择资料位置**
   默认是「文档」文件夹里的 `MoodleStudy`（完整位置类似 `C:\Users\你的用户名\Documents\MoodleStudy`）。你也可以指定其他文件夹。
   以前用过本项目、想继续用原来的学习记录时，把**原来的项目文件夹**选为资料位置即可，已有记录会被沿用，不会被覆盖。
2. **安装运行依赖**
   插件会用 Harness 自带的 Python 建立私有运行环境，首次需要联网下载约 **20 MB**，通常 1–3 分钟。可以在聊天里问“装好了吗”，助手会查看进度；失败会给出原因，网络恢复后重试即可。
3. **连接学校账号**
   助手会在这台电脑的浏览器里打开学校登录页，请**你本人**完成登录（可能包含验证码或双重验证）。第一次连接学校时会自动安装登录组件（约 40 MB 下载）。
   助手不会索要你的密码、验证码或 Token，也不读取浏览器 Cookie；登录结果会用 Windows 自带的加密机制（DPAPI）保存在资料文件夹的 `.private` 目录里，只对当前 Windows 用户可解密。
4. **选择课程**
   助手会列出你账号能看到的课程，按**课程名称**告诉你选择本学期要跟踪的课程（可以多门）。助手不会替你选，也不会把没选的课程加入跟踪。
5. **确认资料范围**
   对所选课程确认一种范围：
   - **完整资料同步**：下载、归档并建立所选课程资料的索引，之后按这份授权自动补齐更新；
   - **只同步课程信息**：只读取课程信息、作业、公告等，不下载课件。
   范围由你本人明确确认；授权范围外的资料不会被下载。
6. **首次同步并完成设置**
   助手采集当前学校信息并按授权同步资料（完整同步可能需要几分钟到十几分钟）。只有同步证据（学校信息采集结果 + 资料同步结果）与你的账号、课程和资料范围匹配时，设置才会被标记为完成；完成后即可开始学习，不需要再等重连。
   采集完成不等于助手已核读或讲解。同步中断、失败或只完成一部分时，助手不会说“设置完成”，而会说明每门课程可用的范围和剩余问题；你可以让它重跑同步，之前已下载成功的内容不会重复下载。

任何一步中断或失败，重新打开聊天说“继续设置”或再次说明需求即可：工具会在每次启动都注册，并**从当前进度继续**，不会删除已有资料。登录成功或更换资料位置后，工具会自动重新连接（约几秒，工具名不变）。

> **学校暂时连不上时也可以继续学习**：已保存在本机的资料、章节讲解和之前的学习记录仍可以使用；只有涉及最新作业、公告、考试安排这类学校信息时，助手会明确说明“当前不是最新线上结果”。网络恢复后让它重试连接即可，不需要重新登录。

## 4. 日常怎么用

设置完成后，直接在聊天里提需求即可，例如：

| 你想做什么 | 可以这样说 |
| --- | --- |
| 学某一章 | “讲解 ECON1220 的 Topic 6” 或 “跟我过一遍第 5 章” |
| 复习学过的内容 | “帮我复习 Topic 5” |
| 按考试要求复习 | “按期末要求复习 Topic 5” |
| 查作业与截止日期 | “这门课下次作业什么时候截止？” |
| 看老师通知 | “老师最近发过什么通知？” |
| 用自己上传的资料 | “用我放进资料文件夹的讲义讲第 2 章” |
| 更新学校信息 | “刷新一下 Moodle” 或 “更新这门课的信息” |
| 安排学习 | “制定这周的学习计划” |

学习时默认一次讲透一个知识点：先具体例子，再解释概念、符号和适用条件，给出示范，最后留一个相关问题等你回答。数学公式用可渲染的公式显示；明确说“讲完整章”“给完整答案”或“不要互动”时，助手会按你的要求一次交付。指定某一章时只处理该章，不会自动扩大成全部课程刷新；回复末尾也不会堆技术日志或核对回执。

**设置完成后也可以调整**：想换课程或资料范围、换资料保存位置、修复运行依赖，都可以直接在聊天里说明，不需要改配置文件或找命令行。更换资料位置时旧文件夹原样保留；旧文件夹的登录凭据不会复制到新位置，如果新位置还没有自己的登录，联网时需要请你本人重新登录一次学校。

## 5. 资料在哪里、怎么备份

资料位置由你在首次设置时选择，里面的内容大致是：

- `Study\`：学习记录、课程资料、本地索引、笔记、错题和复习记录等；
- `config.local.json`：学校地址等本地配置；
- `.private\`：Windows 加密的学校登录凭据。**不需要打开，也不要发给别人。**

**备份**：先关闭 DeepSeek Harness，然后把整个资料文件夹复制到移动硬盘或你自己的网盘。升级、换电脑或重装前建议先备份，并注意要把整个文件夹一起复制（不要只复制 `Study\`）。

**换电脑或重装**：

1. 在新电脑安装 DeepSeek Harness 和本插件；
2. 首次设置时，把复制过来的资料文件夹选为资料位置；
3. 重新连接一次学校账号——加密凭据绑定原来的 Windows 用户，换电脑后需要重新登录；
4. 之前的学习记录会继续沿用。

同一个资料文件夹只对应**一所学校的一个账号**；换学校或换账号请新建一个资料文件夹，不要手工修改旧档案里的配置。

## 6. 升级插件

本试用版是从本地路径或 `.tgz` 安装的，插件页没有“更新”按钮，升级方式是：

1. 在 Plugins 页**卸载**旧版（个人资料目录和运行支持目录会保留）；
2. 安装新的试用包（当前为 `0.6.0-trial.6`）；
3. 打开聊天，按提示继续——资料位置、设置进度、课程选择和资料都在原资料文件夹里；已完成的运行依赖安装会被识别，不需要重装。

如果旧版设置做到一半就升级，不用担心：重新打开聊天后助手会从当前进度继续（继续选课、修复依赖或重跑同步），不会删除已有资料。升级后如果工具没有出现，按提示重启一次 DeepSeek Harness，或让助手重新检查设置状态。

如果没有卸载就直接安装同版本/新版本，会被提示已经安装；先卸载再装即可。

## 7. 卸载与彻底清理

- **只卸载插件**：Plugins 页 → 插件卡片 → **Uninstall**（会弹确认）。个人资料文件夹和运行环境默认保留，重新安装后可继续使用。
- **彻底清理**：卸载插件后，手动删除：
  - 你选择的**资料文件夹**（删除后学习记录、资料和登录凭据都没有了）；
  - 运行支持目录 `C:\Users\你的用户名\AppData\Local\MoodleStudyAssistant`（里面只有运行环境、日志和设置状态，没有学习记录）。
- **重置运行环境但保留记录**：只删除上面的运行支持目录，保留资料文件夹；重新安装插件后按引导继续。

删除前请先备份需要的资料；删除 `.private\` 后下次需要重新登录学校。

## 8. 常见故障与恢复入口

| 现象 | 怎么办 |
| --- | --- |
| 聊天里看不到学习工具，或调用工具失败 | 先对助手说 **“检查 Moodle 学习助手状态”**。这个检查不依赖 MCP 学习工具本身；助手会读出资料位置、运行依赖、学校连接和下一步恢复动作，按提示处理。设置/学习工具在每次启动都会注册，通常重启 Harness 或新开聊天即可恢复；**不要删除资料目录**。 |
| 设置做到一半关掉了聊天/退出了 Harness | 重新打开聊天说 **“继续设置”**。设置进度保存在本机，助手会从当前进度继续（选课、修复依赖或重跑同步），不会删除已有资料或让你从头再来。 |
| 助手说“本地学习档案还没有初始化” | 表示还没选课或初始化中断，不是资料丢失；按助手提示继续设置（通常是选课或重跑同步），已下载的资料会保留。 |
| 学校登录失败或登录页没弹出 | 确认这台电脑能在浏览器正常登录学校 Moodle、网络可达、装有 Edge 或 Chrome；再让助手重新“连接学校”。登录页里的账号、密码、验证码只填在学校页面，不要发到聊天里。 |
| 学校暂时连不上 / 断网 | 已保存在本机的资料、章节讲解和之前的学习记录**仍可以使用**；涉及最新作业、公告或考试信息时，助手会明确说明“当前不是最新线上结果”。网络恢复后让助手**重试连接**即可，不需要重新登录；登录失效才需要你本人重新登录。 |
| 提示工具需要重新连接 | 登录成功或更换资料位置后工具会自动重连（约几秒）；稍等后再试，或让助手检查一次设置状态。仍然不行时重启一次 DeepSeek Harness，让工具重新连接后再继续，不要跳过提示继续核对。 |
| 网络失败（装依赖或同步时） | 网络恢复后重试同一步骤；已下载的资料不会因此丢失，同步是增量的。资料下载成功不等于助手已核读。 |
| 同步中断、失败或只完成一部分 | **设置不会被标记为完成**。按助手说明的每门课程可用范围和剩余问题，让它重跑同步即可；已成功的内容不会重复下载。 |
| 运行依赖安装失败或损坏 | 检查网络和磁盘空间（建议预留 300 MB 以上），然后让助手重新执行运行依赖安装/修复；安装中断或环境损坏时**不要删除学习档案**。仍失败可重启 Harness 后再试，并把错误提示反馈给发布者。 |
| 提示课件缺失、文件有变化或授权失效 | 助手会说明它对当前讲解的影响；需要最新版时明确说“刷新 Moodle”或“重新核对这一章”。 |
| 怀疑学习记录异常 | 先备份资料文件夹，再让助手诊断；不要删除 `Study\` 或重建空白档案来“修复”问题。 |

反馈问题时，请描述你做了什么、看到什么提示；**不要**在聊天或反馈里粘贴密码、验证码、Token，也不要转发 `.private\` 目录。

> 说明：当前 `0.6.0-trial.6` 已包含 2026-11-12 的补充审查修复（重新安装不再覆盖恢复备份、子路径学校身份、HTML 正文内嵌图片、插件教学保存新入口 `study_teaching_save`、资料目录保护）、发布前审计修复（资料目录保护扩大到整个插件安装包、后台任务按 ID 查询、依赖安全告警清零、发布验证目标统一），以及同日源码维护修复（旧复习写入口退役、公共原子写入与不变页面不重写、CLI 参数前置校验），安装或升级到该包后生效；旧包仍可重新执行依赖安装步骤，同样不要删除学习档案。验证结论见 [CHANGELOG](../CHANGELOG.md) 的 2026-11-13 与 2026-11-12 条目，技术细节见 [插件发布说明](PLUGIN_RELEASE_NOTES.md) §0。

## 9. 已知限制

**本次试用版的验证范围**：`0.6.0-trial.6` 把 2026-11-12 的源码维护修复（旧复习写入口退役、公共原子写入与不变页面不重写、CLI 参数前置校验）纳入插件包，并通过离线回归与隔离解包验证（Node 299 项、`tests/` Python 133 项、`tools/study` Python 686 项通过；`npm audit` 0 漏洞；独立解包后包内源码与工作区逐字节一致，`verify-plugin` 36/36、`verify-study-tools` 12/12），技术细节见 [CHANGELOG](../CHANGELOG.md) 的 2026-11-13 与 2026-11-12 条目与 [插件发布说明](PLUGIN_RELEASE_NOTES.md) §0。**本包按计划没有安装到当前 Harness、也没有对外发布**，因此不包含本版的真实安装/连接验收。此前版本使用模拟学校响应做过独立验收（隔离环境，不接触真实学校账号），覆盖设置中断后继续、断网本地学习、同步完成判定与章节核对等。**`0.6.0-trial.4` 的历史记录**还包括真实 DeepSeek Harness 安装、真实学校连接（使用已保存的 Windows 加密凭据）与真实增量资料同步、插件内教学保存、完整重启后的接续验收，以及卸载/重装和降级 `0.6.0-trial.3` 后升级的数据保留验收；这些记录不能当作 `0.6.0-trial.6` 的重测结果。以下内容**没有**验证，需要你本人在真实环境确认：本包的真实 Harness 安装与完整首次设置、真实学校 SSO/MFA 页面重新登录（含浏览器登录组件）、DeepSeek Harness 桌面界面鼠标点击安装的完整走查与截图、换 Windows 账户后的加密凭据解密、其他学校/电脑。

- 仅支持 Windows；学校登录依赖 Windows 的凭据保护和系统 Edge/Chrome。
- 真实学校账号连接与资料同步的现场验收属于 `0.6.0-trial.4` 的历史记录（已保存的 Windows 加密凭据，实际学习档案的本地副本）；`0.6.0-trial.6` 只完成离线测试与隔离解包验证，**未覆盖**本包的真实 Harness 安装、真实 SSO/MFA 重新登录页面、桌面界面鼠标点击安装的完整走查，以及全部学校/电脑/Windows 账户组合。
- 不同学校、不同电脑、不同 Windows 账户的安装表现尚未全部验证。
- 学校必须启用 Moodle Mobile Web Service，具体接口权限由学校控制，部分资料可能无法读取。
- 首次使用需要联网下载运行依赖；网络受限时会失败，恢复网络后可重试。
- **本地保存不等于离线推理**：断网时只保证读取本机资料与本地教学记录可用，不承诺模型离线推理；模型调用仍依赖 Harness 当前使用的模型服务。
- DOCX/PPTX 资料没有页图，只能读取抽取的文字；公式和图表应以 PDF 原页为准；扫描件 OCR 结果可能有误，需要对照原件。
- 插件不执行任意命令，也不下载授权范围外的内容。

## 10. 隐私与安全

- 学校接口只读：不提交作业、不代替作答、不发帖、不修改完成状态、不发邮件。
- 密码、验证码由你本人在学校网页输入；插件不读取浏览器 Cookie，不把 Token 写进聊天、日志或配置。
