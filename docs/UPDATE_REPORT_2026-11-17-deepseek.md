## 本次改进

- 教学前通过 `study_check_chapter` 按本章来源时间核对；优先修改时间，其次创建时间。本地原件完整、来源时间一致时不再下载；同聊天复用有效回执。`strict` 保留作显式内容比对诊断。
- 已有完整课程授权覆盖本章缺件、新增补充资料和丢失原件的恢复；章节归属含糊时返回候选，不擅自扩大到其他章节或全科刷新。
- 修复原件缺失又遇远端更新、部分补齐失败、索引恢复、同模块与整章范围混用、时间基线及替换中断恢复。账号、课程页面和本地批注保护继续有效。
- 新版原件与阅读入口验证成功后，仅清理本次同源替换链中的受管理旧原件；旧资料 ID、哈希、来源及历史原答保留，缺失或删除状态明确记录。
- 扫描 PDF 与图片没有文字层时，检查原页渲染并返回需看图的页面，不强制先完成 OCR；损坏、无法渲染或纯空白材料仍阻断。同步成功不代表实际核读或学生掌握。
- 当前考试和截止信息先核读适用的最新教师通知；教学实际变化及时保存并回读。资料来源时间未知、缺件或同步失败时暂停相关教学。

此次合并还带入开发分支中此前未进入公开分支的插件源码与构建工具。这些文件供维护与后续打包使用，不代表插件包已经发布。

对合并后的公开源码运行完整 Node、安装入口 Python、学习工具 Python 检查；具体数量见本次中英文更新日志。运行代码与 `47f6799` 一致，合并保留远端教程并整理文档。

检查使用虚构档案和模拟学校响应；本轮未验证真实 DeepSeek 模型、Harness 界面、学校登录或在线课件下载。来源时间相同不能检测服务器改了内容却未更新时间的情况。
