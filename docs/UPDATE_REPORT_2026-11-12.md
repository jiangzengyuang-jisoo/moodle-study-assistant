# 2026-11-12：教学接续修复与复习流程精简

[English](UPDATE_REPORT_2026-11-12.en.md) · **简体中文**

本次更新面向公开版 `codex` 分支，汇总 `74e589f` 和 `e689499` 两个代码提交。更新后，教学进度读取与保存采用一致规则，旧复习入口使用当前流程，未变化的页面不再重复写入。

## 修复了什么

- **教学接续更一致。** 课程总览、单科接续和记忆查询共用教学位置选择逻辑；作业范围、已记录教学位置和掌握证据分开呈现。旧课补录不会仅凭保存时间覆盖较新的教学接续，冲突保留待核对。
- **保存有回执，重试不重复记账。** `teaching-save` 在共享锁内保存带实际发生时间和聊天来源的学习事件，再回读确认。过期请求拒绝覆盖；已答、跳过或已展示答案的题不再继续显示为当前待答题。旧原答、评分和 FSRS 历史保留。
- **移除旧复习分支。** `review.py due` 使用当前选题预览，`render` 使用统一页面入口。退役的 `record` 命令明确提示使用 `daily.py attempt`，旧档案也不能绕过题目和答案曝光校验。
- **减少重复文件操作。** 状态、资料缓存、资料版本和页面复用安全写入；内容相同的页面保持原文件，新鲜度检查复用已经生成的计划内容。保留锁、恢复、快照校验和档案时区行为。

## 验证依据

对应代码提交的公开版回归检查共 **795 项通过**：学习工具 Python 573 项、安装与入口 Python 92 项、Node 130 项。使用项目内临时目录、虚构学习记录和模拟学校响应；这些结果不是个人本地版测试数量。

后续运行审查还核对了临时档案上的 `study.cmd continue / today / continue`、保存成功但页面生成失败后的重试恢复、不同档案时区的前后结果，以及写入失败时原文件保留与临时文件清理。未变化页面的检查样本中，9 个页面均未重写。未发现需要回滚的回归。

本次发布整理仅补充报告与文档链接，未再次修改运行代码，也未重复计算上述测试。公开版未进行真实学校登录、下载或全新电脑安装验证；个人本地版的真实媒体读取结果不能替代公开版验证。减少写入不等于整体性能已量化提升。

## 已有用户如何升级

按[保留学习记录的升级步骤](新手使用指南.md#从旧版更新)更新 `codex` 分支代码，保留 `Study/`、本地配置和凭据，无需重建个人档案。下载新源码不会自动替换电脑上的旧安装。

教学记录保存与漏记核查见[记忆与教学接续说明](MEMORY.md#教学接续保存与漏记检查)，复习入口见[工具说明](TOOLS.md)。工具只能确认实际调用保存入口的事件，不能保证所有聊天都已记入档案。

## 范围与保留项

本次同步包含公开源码、测试和文档，不包含个人学习记录、课件、凭据或个人本地版归档脚本。DeepSeek 分支不在本次范围内。

公开版的指定文件下载与课程持续同步仍是两个有效入口；其中少量文件名及地址检查的重复逻辑尚未合并。本次不把它描述为已修复，也不删除任一下载功能。
