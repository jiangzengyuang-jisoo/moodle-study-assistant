# 第二阶段入口与诊断验收 · 2026-10-31

版本 0.3.0。本次范围是公开版的中文文字上手向导、诊断和使用须知；学习仍使用现有 AI 客户端。没有修改作者个人学习系统，没有推送或发布此版本。

## 验证结果

合计 **321 项通过**：262 项学习工具、30 项 Node/API/桥接、26 项新增上手与诊断、3 项登录与加密存储。最后调整学校核读恢复提示、连接失败的下一步和缺失文件的恢复保护后，重新运行入口和登录测试，29 项全部通过；学习核心及 Node 代码未在这些调整中修改。

新增测试覆盖：

- 空目录诊断不创建档案，不联网；已有课程、原始作答、错题、配置和授权字节保持不变。
- 缺 Python、缺 Node/npm、缺依赖、解释器损坏分别给出相应建议；损坏档案、错误配置类型和时区冲突阻止向导写入，不删除后重建。已有档案却缺配置、档案缺失却仍有历史备份时要求恢复，不按默认学校或空白档案重新初始化。
- 根据当前文件依次提示安装、连接、选课和进入学习；取消安装/连接不会执行操作，失败不会自动重试，再次打开仍停在实际未完成步骤。
- 默认诊断不验证授权、不联网；显式连接检查只调用一次现有 check 入口，不采集、下载或推进核读。
- 模拟授权失效、学校权限不足、DPAPI 解密失败、超时和未知错误，输出中文建议，不回显输入中的敏感标记、原始异常或路径。
- 已保存授权、连接验证成功、采集待核读、核读已保存但页面待恢复、采集中断/失败分别展示；旧范围和被改动快照不展示为已核读。
- 自定义/已移动的客户端配置给出提示，诊断不覆盖原文件。
- 实际运行 Windows PowerShell 和两个 cmd 启动器，验证中文及空格路径、无 Python 提示、结构化诊断、菜单提示和正常退出；前后文件内容相同。
- 菜单复用现有 setup.ps1、auth.py 和 courses 入口，使用参数数组；没有新增学习状态写入实现，也不生成虚构聊天 ID 或提前刷新。

文档本地链接与 Git 空白检查通过。更新了 README、更新日志、AI 工作规则、新手指南和工具说明。

## 复现

在公开项目中运行：

```powershell
.venv/Scripts/python.exe -B -m unittest discover -s tests -p 'test_*.py'
.venv/Scripts/python.exe -B -m unittest discover -s tools/study -p 'test_*.py'
node --test tests/*.test.mjs
```

若受限环境中的系统临时目录不可写，将 TEMP 和 TMP 指向本项目被忽略的 tmp 子目录后运行；不用修改凭据保护方式。诊断自身可用 `diagnose.cmd -Json -NoPause`，缺少安装步骤返回 1 是预期结果，不会因运行诊断自动安装。
