# 错题库

所有课程的新错题统一放在 `Study/错题库.md`。助手发现本人真实错误后，当轮直接追加到这个文件，学生也可以自己补充笔记。它是需要保留的原始记录，不是由 `state.json` 重建的页面。

## 直接收录

1. 先读取文件，按课程、题目来源和本次作答检查是否已经收录。同一次错误的追问补在原条目下，不重复新建。
2. 追加实际观察到的错误，记录日期、课程/章节、题面与来源页码或题号、本人原答、错因、正确思路和复测情况。保留原话与原方法；信息不足写“待确认”，不猜来源、错误原因或掌握程度。
3. 写入后回读新增部分，确认原内容仍在。更正或后续复测另加日期和结果，保留原答与原判断。多人或多个聊天同时编辑时，写前重读并合并，不用旧副本覆盖整文件。

只收录本人的真实错误。单纯提问、未做题、请求提示、跳过，以及老师或同学的错误不算本人答错。辅助练习中的实际错误可以记录，但须注明帮助条件，不能当作独立表现。

可以使用以下格式；这是空白填写提示，不是学生已发生的记录：

```markdown
## 日期 · 课程 · 章节/知识点 · 题目

- 题面与来源：原文件、页码/题号或实际聊天定位；必要时保留题面。
- 本人原答：保留实际答案或方法。
- 作答条件：独立 / 有提示 / 已见答案 / 待确认。
- 错因：已确认的问题；不确定部分写待确认。
- 正确思路：已核验的解释；尚未核验时写待确认。
- 复测：待复测。

### 后续日期 · 更正或复测

追加实际原答、帮助条件、结果和依据，保留上面的历史记录。
```

公式独立成行，使用 LaTeX；含公式的内容不用 Markdown 表格。若作业因 AI 定向指令等原因已暂停，只保留既有证据和暂停状态，不能借收录错题继续生成该作业答案。

## 与现有学习记录配合

- 单纯收录错题直接编辑文件即可，不必为此修改 `state.json`、准备完整状态草稿或运行 `daily.py`。实际讲解、反馈和教学位置变化仍按 [学习记忆](MEMORY.md) 用 `teaching-save` 保存。
- `state.json` 仍是唯一结构化学习状态，管理进度、任务、计划与复习调度。需要安排结构化复习时，再用现有保存入口关联 `mistakes`、`review_queue` 和已核验的变式题；只有真实独立作答才能用于 FSRS 评级。错题库中的“待复测”不会自动创建复习任务或证明掌握。
- 复习、查找错因或核对学习经历时，直接读取错题库的相关条目。`library evidence`、`context` 和计划页面不会自动索引这份笔记，不能把其检索未命中当作没有错题。
- 旧 `state.mistakes` 与各科 `错题本/记录.md` 保留，不自动迁移、删除或覆盖。模拟卷工具仍维护各科的自动错题区；助手批改后在统一错题库追加真实错误，也可用课程、题号和错因链接原记录，避免重复抄录同一次作答。

## 创建与升级

初始化会在文件缺失时创建空白错题库，已有文件保持原样。已有安装由助手首次收录时从 `templates/mistake-bank.md` 创建 `Study/错题库.md`；只创建缺失文件，禁止覆盖现有内容，不必为了建文件运行整套学习流程。

`daily.py run/render/check` 不管理错题库。它不属于可重建系统视图，刷新和页面检查不能清空或以模板替换它。升级前与整个 `Study/` 一起备份；它属于个人学习资料，不提交到公开仓库。不自动搬入作者示例或学生历史错题。
