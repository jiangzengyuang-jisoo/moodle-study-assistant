# 2026-11-16：按章同步、异常恢复与扫描课件阅读

[English](UPDATE_REPORT_2026-11-16.en.md) · **简体中文**

本次更新汇总公开版 `codex` 分支截至 `3659998` 的当天改进。学习前按本章云端来源时间核对资料，已有授权下自动补齐缺件，并为没有文字层的扫描课件提供原页阅读入口。

## 主要改进

- **减少重复下载。** 优先使用云端修改时间，缺失时使用创建时间；本地原件完整、来源时间一致时复用。旧档案没有时间基线时允许一次下载建立基线，同聊天继续学习复用本章回执，新章节只检查新增范围。
- **已授权课程自动补齐。** 缺少本章课件、新上传补充材料或已登记原件丢失时，按当前账号、页面和持续授权补齐，无需重复询问下载许可，也不因此执行全科刷新。
- **资料更新保留历史证据。** 新版文件和阅读索引验证成功后，只清理本次替换链中的受管理同源旧原件，保留旧资料 ID、来源、哈希和原答历史。本地批注、来源不匹配或更新失败时保留原件；已丢失的历史原件明确记为缺失。
- **失败后能够恢复。** 修复索引失败后远端时间未变而无法恢复、原件缺失又遇远端更新、替换链删除中断等情况。章节回执复用前检查本地完整性与阅读索引；失败后需处理原因并明确重试。
- **扫描课件可以进入阅读流程。** 没有文字层的 PDF 或图片会检查原页能否渲染，并列出需要看图的页面；同步成功可保存来源时间，不要求先完成 OCR。损坏、无法渲染或纯空白材料仍不能通过。可进入阅读流程不代表助手已经核读，更不代表学生掌握。
- **收紧信息和来源判断。** 修复同章空资源遗漏、HTTP 200 错误 JSON 冒充文本、跨校资料来源混淆和首次选课入口提示。当前考试及截止信息须核读适用的最新教师通知，教学变化及时保存并回读。

## 已有用户如何升级

按[保留学习记录的升级步骤](新手使用指南.md#从旧版更新)更新 `codex` 源码，保留 `Study/`、本地配置、凭据和已有课程授权，无需重建个人档案。下载新代码不会自动替换已有安装。

继续在聊天中提出学习请求，由助手先定位本章资料并调用 `ensure-chapter`；资料 ID 可选，名称不明确时由助手核对课程目录。同步后仍须核读正文或原页才能教学。已有失败回执仅在原因处理后明确使用 `--force` 重试；时间未知、同章缺件或同步失败时暂停相关教学。
